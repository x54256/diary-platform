# 01 — 每日自动全量备份及失败重试

**What to build:** 系统每天在可配置的本地时间自动创建一次全量备份任务，默认时间为 `02:00`、时区为 `Asia/Shanghai`。任务调用现有备份服务生成加密备份包并保存到配置目录；失败后自动重试一次，两次失败则记录失败原因。应用启动不补执行，下一次执行仍按下一日计划时间进行。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 默认每天 `Asia/Shanghai` 02:00 触发一次全量备份
- [ ] 触发时间支持配置，非法时间配置在启动时明确报错
- [ ] 备份包成功生成并写入备份记录
- [ ] 失败自动重试一次，最终失败记录状态和原因
- [ ] 应用启动不触发补执行
- [ ] 调度器和重试逻辑具备自动化测试

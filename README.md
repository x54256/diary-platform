# 日记管理平台

个人日记与自我认知平台，提供日记录入、AI 整理与分析、事件浏览、日程和行动项管理，以及模型配置、备份恢复等管理能力。

## 开发入口

- [本地开发](docs/部署运维/本地开发.md)：环境、配置、数据库准备、启动与验证。
- [部署发布](docs/部署运维/部署发布.md)：镜像构建、交付、更新与回退。
- [文档索引](docs/README.md)：按业务模块查找功能约定、实现设计及规划。
- [产品设计总纲](docs/产品设计总纲.md)：产品边界、当前能力与未来范围。
- [领域术语](CONTEXT.md)：跨模块概念的统一定义。
- [开发约束](AGENTS.md)：移动端表单和后端排查约束。

## 技术组成

| 层次 | 当前使用 |
|---|---|
| 前端 | Nuxt 3、Vue 3、TypeScript、TailwindCSS、Pinia |
| 后端 | Python 3.11、FastAPI、SQLAlchemy |
| 数据存储 | PostgreSQL、pgvector；音频使用 MinIO |
| AI | 管理端配置的渠道、模型与业务用途；应用内及 Skill 两种处理路径 |
| 部署 | Docker 应用镜像、Nuxt 服务、Uvicorn、Nginx |

依赖版本以 [后端 requirements](backend/requirements.txt)、[前端 package](frontend/package.json) 和锁文件为准。

## 仓库结构

```text
diary-platform/
├── backend/       # 路由、模型、服务、迁移、调试脚本与测试
├── frontend/      # 页面、组件、状态、请求封装与测试
├── skills/        # 日记整理、要点、关系、分析和总流程工具
├── docs/          # 按业务能力组织的维护文档
├── knowledge-graph/ # 图谱原型、实验与验证材料
├── docker/        # 应用镜像与容器启动、代理配置
└── nginx/         # 独立外部网关配置
```

运行配置独立维护。前端默认路径 `/secret/`，业务接口默认路径 `/diary/api`，后端 API 文档路径 `/diary/docs`。

## 当前范围

日记、语音、热词与人物关系、日程、日记行动项、备份恢复和模型配置已有代码实现；具体覆盖与已知差异在模块文档说明。

搜索与定期回顾的原实现已移除，回顾底部菜单保留，行为与其他空菜单一致。知识库以事件要点、向量和事件关系为当前事实层能力，相关后续层与应用规划继续保留，文档入口见 [知识库](docs/知识库/README.md)。

应用内整理与分析由代码任务执行；对应 Skill 有独立的交互、确认和保存流程。两种路径的共同设计、实现范围及差异见 [日记管理](docs/日记管理/模块说明.md)。

# 去重事件内容池加明确配对列表：单批组织实验

本次由同一宿主 agent 阅读冻结规则，再以去重 events 内容池加明确 pairs 列表的批量组织方式，语义判断全部 11 个事件、83 个正式要点和 55 对。没有调用模型 API、数据库或网络，没有读取 source.json、recall.json、pairs 目录或其他方案结果。只写本实验的两个输出文件。

每对同时检查 A→B 与 B→A，依据后续、引发、提及的优先级判断；同人、同主题、同项目或日期先后不单独构成关系。RELATED 给出双方最小充分要点。先选证据后普通复读其两侧，检查是否仍支持方向和描述；这是同一判断过程中的自检，不是独立验证。计划仅描述为计划，没有写成已经执行。

存在额外回查输入：首次直接读取完整 batch-input.json 时，工具输出发生截断；随后去掉要点 UUID 等冗余信息，以保留全部 summary 和 detail 的紧凑格式复读完整内容池及完整配对列表。该输出又截断了事件 8 中部，随后单独补读事件 8 的全部 19 要点。因此，本次是完整内容池加明确配对列表的一次批量语义处理，但不能声称一次显示即完整摄入、没有回查；该显示限制会影响与其他组织方式的严格比较。

结果为 RELATED 3 对（P09、P37、P48）、NO_RELATION 51 对、UNRESOLVED 1 对（P06）。P09 和 P48 的后续是同一普通心理学学习恢复事项中形成新的时间安排打算，未认定已经开始执行。P06 的具体缺口是荒废、尝试重启和仍未知恢复办法之间缺少可定位的阶段对应，无法分清新进展与重复状态描述。

结构检查使用脚本核对 55 个 pair_id 恰好各一次、关系双方属于对应事件对、引用要点均属于本事件且非空。结构检查不证明语义正确，也未被称为独立验证。

从第一次输入读取结束至结果文件首次生成约 109 秒（宿主 JavaScript Date.now 的墙钟差，含工具调用和判断）；不等于纯推理时间，也不等于模型 API 耗时。无可靠 API 用量，因此不提供 Token 数。

这只是相同宿主 agent 上的批量组织实验，不是旧 Qwen 生产调用的复现，也未验证旧生产模型、提示词、上下文窗口、采样及服务实现。没有外部真值、源原文或独立复核者参与，语义边界仍可能有争议；完整输入显示发生截断及补读也应作为实验局限保留。

# 两个知识库 Skill 的事件范围统一

日期：2026-10-23。

要点提取和事件关系两个 Skill 均以全部事件为处理范围。已清理主说明、参考资料、输出约定和构造示例中的重要性、等级及相应筛选表述；运行脚本不读取这些字段，新来源快照和入库包不携带它们。

- 要点常规保存继续完整覆盖全部来源事件。补充入口改为通用“缺失事件追加”：只看节点和正式要点是否已保存，不区分任何等级；遇到部分保存仍停止，不覆盖原结果。
- 新补充包版本 2 使用通用协议，嵌入来源为身份与内容字段的投影；原文件保持，另绑定原文件指纹。历史包仍支持状态查询，新写入须重新预检。
- 关系数据库适配不再查询或核对等级字段，来源输出仅保留身份、顺序、正式要点及向量指纹。纯计算入口也按字段白名单生成来源，额外输入元数据不会带入结果。
- 数据库原字段和历史快照不修改，历史不可变指纹仍按原内容核对；新增投影不把旧元数据当事件事实。测试中保留多种旧字段取值，用于验证变化不会影响范围及输出。

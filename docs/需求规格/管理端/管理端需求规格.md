# 管理端需求规格

> 功能状态：已实现  
> 事实基线：2026-07-31 代码

## 1. 目标

管理端集中承载影响整个系统的数据维护和运行配置，避免普通用户接触高风险系统操作。

## 2. 访问控制

- 管理端使用独立登录入口和页面布局。
- 当前只有用户名为 `admin` 的账号拥有超级管理员权限。
- 未登录访问管理端时跳转到管理端登录页。
- 已登录但没有权限时进入无权限页面。
- 所有管理端接口必须在服务端验证超级管理员身份。

## 3. 功能地图

| 功能 | 状态 | 说明 |
|---|---|---|
| 备份与恢复 | 已实现 | 系统数据导出、导入预检、恢复、记录查询和定时备份 |
| 模型管理 | 已实现 | 维护语言模型和语音识别模型能力清单 |
| 渠道管理 | 已实现 | 维护调用地址、加密密钥和渠道支持模型 |
| 模型设置 | 已实现 | 为整理、分析、对话、语音转文字选择默认模型 |
| 环节配置 | 已实现 | 为整理与分析的具体环节覆盖模型和思考模式 |

## 4. 导航

管理端侧边栏固定提供：

1. 备份与恢复。
2. 模型管理。
3. 渠道管理。
4. 模型设置。

## 5. 全局规则

- API 密钥只允许写入或清空，不向前端返回明文。
- 高风险操作必须在服务端校验权限和业务前置条件。
- 管理端修改模型配置后，对新启动或恢复执行的任务生效。
- 页面必须同时适配桌面端和移动端；移动端表单控件实际字号不得小于 `16px`。

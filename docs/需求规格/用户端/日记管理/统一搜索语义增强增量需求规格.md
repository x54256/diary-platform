# 统一搜索语义增强增量需求规格

> 文档类型：增量需求规格
> 需求基线：2026-08-31 已确认方案
> 性质：在已验收的《统一搜索功能需求规格》关键词搜索之上保留语义向量分支，并将其向量来源统一为事件关系图谱使用的 `body` 检索向量。

## 1. 变更摘要

统一搜索继续采用“关键词 + 语义”混合检索，两个分支并行召回并使用 RRF 融合排序。

语义分支不再使用事件内容、自我理解和认知分析三层向量，改为与事件图谱共用一套来源事件 `body` 向量。这套向量只在用户首次点击“AI 分析”时生成，不由定时任务生成或补算。

## 2. 检索范围

### 2.1 关键词分支

关键词分支行为保持不变，继续检索并高亮现有可检索文本，包括：

- 事件标题；
- 事件正文 `body`；
- 感受与反思；
- 当前有效分析轮次的事件级分析文本和问答。

标签不参与用户搜索的关键词排序。

### 2.2 语义分支

语义分支只匹配结构化事件的 `body`：

- 不将事件标题写入语义向量。
- 不将感受、反思、标签、自我理解分析、认知分析或行动建议写入语义向量。
- 查询文本生成一个查询向量，与事件 `body` 向量按余弦距离检索。
- 命中任一 `body` 向量即视为该事件在语义分支命中，最终按事件去重。

## 3. 统一事件向量

### 3.1 向量粒度

每个来源结构化事件生成以下向量：

| 类型 | 文本 | 数量 | 用途 |
|---|---|---|---|
| 完整 `body` | 按原顺序合并全部非空 `body` 自然段 | 每事件 1 个 | 保留事件整体语义 |
| 自然段 | 单个非空 `body` 自然段 | 每个自然段 1 个 | 避免多内容在整体向量中相互稀释 |

自然段是技术检索分块，不是语义内容块或业务实体。搜索结果仍以事件为单位，不展示块级卡片。

### 3.2 向量生成时机

- 只有 `organized` 日记首次点击“AI 分析”时生成事件向量。
- embedding 调用在分析管线中同步完成，结果暂存于任务状态，最终与标签、分析、事件知识和图谱关系在同一事务中发布。
- 向量生成失败时首次分析失败，不得发布空向量或部分向量。
- `analyzed` 日记的重新分析不重建向量。
- 取消每日定时向量生成、静默窗口补算和存量自动对账。

### 3.3 存量与未分析日记

- 不回填已处于 `analyzed` 状态的存量日记向量。
- 不为未首次分析的 `organized` 日记生成向量。
- 没有向量的事件仍可通过关键词分支被召回，不因语义索引缺失而从统一搜索中消失。
- 旧三层向量退出搜索查询路径，新流程不迁移旧三层向量，也不按新规则自动回填。

## 4. 检索与融合排序

### 4.1 语义召回

- 在统一 `body` 向量表上按余弦距离查询。
- 查询必须按 `user_id` 隔离，过滤已软删除日记，并继续支持日期范围。
- 同一事件的多个向量同时命中时，该事件的语义排名使用最高相似度。
- 后端返回命中的向量粒度；命中自然段向量时同时返回其 `body` 数组下标，但不返回独立块对象。

### 4.2 混合融合

- `mode = hybrid` 时，分别取关键词分支排名与语义分支排名，按现有 RRF 规则融合。
- `mode = keyword` 时只走关键词分支。
- `mode = semantic` 时只走语义分支。
- 默认模式保持 `hybrid`，前端不新增模式切换控件。
- 融合后继续按事件去重、分页，并复用现有统一事件卡。
- 事件标签只用于图谱历史候选加权，不参与用户搜索的语义排序或 RRF 融合。

## 5. UI 影响

- 复用现有搜索入口、加载态、空态和统一事件卡，不新建搜索页或块级卡片。
- 关键词命中仍按现有规则高亮。
- 语义命中统一标识为“正文”，不再展示 `fact / self_understanding / cognition` 三层命中标记。
- 语义分支无结果时，`hybrid` 模式仍展示关键词分支结果。

## 6. 权限、隐私与性能

- 事件向量和查询向量使用同一 embedding 模型与维度。
- 换模型或变更维度时，已有向量必须统一重算；不得在同一索引中混用不同模型或维度。
- 生成事件向量的 embedding 请求只发送 `body` 文本，不发送用户标识、日记 ID、标题、感受、反思或分析结果。
- 生成查询向量的 embedding 请求只发送用户输入的查询文本，不发送用户标识或筛选条件。
- 向量生成和查询错误不得在日志中输出完整 `body`、请求认证头或 API Key。

## 7. 验收标准

- `organized` 日记首次分析时，每个结构化事件都生成一个完整 `body` 向量和全部非空自然段向量。
- 向量文本不包含标题、感受、反思、标签或分析结果。
- 图谱历史候选召回与用户语义搜索读取同一套事件向量。
- 向量化失败会阻止首次分析的全部发布。
- 每日定时向量生成、静默窗口补算和存量自动对账不再运行。
- 存量已分析日记和未首次分析日记可通过关键词分支召回，不因无向量而消失。
- `hybrid` 按关键词与语义两路排名执行 RRF 融合，结果按事件去重并稳定分页。
- 搜索过程全程按 `user_id` 隔离，过滤软删除日记并遵守日期范围。
- 前端不展示三层语义命中标记，不展示独立自然段卡片。

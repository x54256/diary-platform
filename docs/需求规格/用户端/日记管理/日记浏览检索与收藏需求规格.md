# 日记浏览检索与收藏需求规格

> 功能状态：已实现
> 事实基线：2026-07-31 代码

## 1. 目标

用户通过日历、时间线、标签和收藏定位本人日记及事件。

### 2.2 模块二：日记浏览与查找

### 浏览

- **默认视图**：日历视图，可切换到时间线视图
- **日历视图展示**：每天显示心情颜色 + 整理/分析状态标记（未整理的日记有灰色点等特殊标记）
- **时间线视图**：按时间倒序列出日记

### 筛选

- **按标签筛选**：通过标签分类过滤日记

## 3. 当前视图

- 首页提供日历、时间线和收藏三种视图。
- 日历按月展示每日状态和可用心情；同日一篇直接进入详情，多篇进入日期列表。
- 时间线按日记日期和创建时间倒序展示。
- 收藏列表统一展示日记收藏和事件收藏，并链接到所属日记或事件。
- 已软删除日记及其事件不得出现在任何视图。

## 4. 收藏规则

- 用户可以收藏或取消收藏一篇日记或一个事件。
- 收藏操作幂等，一条收藏只能指向一种目标。
- 同一用户对同一目标最多一条收藏。
- 用户只能读取和维护本人收藏。

## 5. 验收标准

- 日期和标签查询均按当前用户隔离。
- 收藏状态刷新后保持一致，删除日记后相关收藏不可见。

# 日记批注需求规格

> 功能状态：已实现  
> 事实基线：2026-07-31 代码

## 1. 目标

用户可以对结构化日记或分析结果中的具体文本划线并记录评论，使后续思考与原内容保持精确关联。

## 2. 批注范围

- 日记级字段、事件字段和分析项可以作为批注目标。
- 批注保存起止段落、字符偏移、选中文本及前后文。
- 一个批注可以维护评论；评论支持新增、修改和删除。
- 批注、评论采用软删除，保留删除人、删除时间和原因。

## 3. 内容变化

- 编辑结构化内容后，系统重新定位受到影响的批注。
- 重叠批注可以合并，并通过 `merged_into_id` 保留去向。
- 无法继续定位的批注软删除，不能错误附着到其他文本。
- 分析轮次变化时，分析项批注仍绑定原分析项，不静默迁移到含义不同的新内容。

## 4. 权限

- 只有日记所属用户可以读取和维护批注。
- 批注引用的事件、字段或分析项必须属于目标日记。
- 已删除日记的批注不通过普通用户接口返回。

## 5. 验收标准

- 选区跨段落时能够稳定保存和恢复。
- 内容编辑后批注正确保留、合并或失效。
- 用户不能通过批注 ID 访问其他用户数据。

# 个人资料需求规格

> 功能状态：已实现  
> 范围：账号信息、热词管理、人物关系管理

## 1. 目标

用户维护与本人相关的专有词汇和人物关系，提升语音识别准确率，并为后续功能提供基础资料。

## 2. 热词管理

- 用户可以查看、新增、修改和删除本人热词。
- 热词去除首尾空格后不能为空，最大长度为 100 个字符。
- 同一用户的热词按不区分大小写的方式保持唯一。
- 不同用户可以保存相同热词。

## 3. 人物关系管理

- 用户可以查看、新增、修改和删除人物关系。
- 人物信息包括姓名、常用名、性别和与用户的关系。
- 姓名与关系不能为空，单项最大长度为 100 个字符。
- 一个角色最多保存 20 个常用名；空常用名被忽略。
- 同一用户范围内，姓名和全部常用名不得相互重复，比较时不区分大小写。

## 4. 语音识别联动

- 热词、人物姓名和人物常用名共同组成当前用户的 ASR 词表。
- 用户资料变化后，系统在语音转写需要时重新同步有效词表。
- 个人词表不得影响其他用户的语音识别任务。

## 5. 验收标准

- 用户只能看到和修改本人资料。
- 重复热词、姓名或常用名被明确拒绝。
- 新增或修改资料后，后续语音任务使用更新后的词表。
- 移动端所有可编辑控件实际字号不小于 `16px`。

# 账号与访问需求规格

> 功能状态：已实现  
> 事实基线：2026-07-31 代码

## 1. 目标

系统允许个人用户建立账号并安全访问本人数据，同时阻止未登录用户访问受保护页面和接口。

## 2. 功能范围

- 用户使用唯一用户名和密码注册，注册成功后直接登录。
- 用户使用用户名和密码登录；凭据错误时统一提示“用户名或密码错误”。
- 登录成功后客户端保存访问令牌，并可读取当前用户信息。
- 每次成功鉴权后，服务端返回续期令牌，将有效期向后延长 30 天。
- 用户退出时客户端删除令牌并返回登录页。
- 未登录用户访问受保护页面时跳转至登录页，登录后返回原目标页面。

## 3. 业务规则

- 用户名去除首尾空格后不能为空，且在系统内唯一。
- 普通用户只能访问本人日记、日程、热词、人物关系及相关数据。
- 当前超级管理员由用户名 `admin` 判定；管理端接口必须再次执行服务端权限检查。
- 当前退出采用无状态 JWT 机制，服务端不维护令牌黑名单。

## 4. 非目标

- 找回密码、修改密码、邮箱或手机验证。
- 多因素认证、账号冻结和角色管理。
- 第三方账号登录。

## 5. 验收标准

- 新用户名能够注册并直接进入系统，重复用户名返回冲突提示。
- 正确凭据能够登录，错误凭据不能区分用户名不存在或密码错误。
- 无令牌或无效令牌不能读取受保护资源。
- 普通用户不能进入管理端，也不能调用管理端接口。

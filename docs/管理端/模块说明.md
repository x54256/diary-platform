# 管理端模块说明

核对基线：2026-10-29。管理端承载管理员的数据维护和运行配置。按业务能力集中组织，功能约定说明目标与操作规则，实现设计说明实际机制及差异。

## 1. 访问与导航

管理端使用独立登录入口 `/admin/login` 与布局，默认 `/admin` 跳转 `/admin/backup-restore`。当前超级管理员由用户名 `admin` 判定。未登录进入登录页，其他用户进入无权限页；所有管理接口再次执行服务端权限检查。认证与续期机制见[账号与权限](../账号与访问/账号与权限.md)。

侧边栏入口为备份与恢复、模型管理、渠道管理、模型设置。搜索索引与定期回顾功能已移除，不再作为管理能力列出。

## 3. 全局约束

- 密钥通过受控配置写入、加密保存和运行时解密；查询只展示是否配置，不返回密文或明文。
- 破坏已配置用途的删除、禁用和清空密钥操作须受引用保护。
- 导出、预检和导入入口展示敏感范围及结果，不在报告中展示密码、日记正文或密钥。
- 配置何时生效取决于调用方：逐调用读取与任务冻结快照分别说明，不能统一承诺“恢复任务自动采用新配置”。
- 移动端可编辑控件实际字号至少 `16px`，保留用户缩放能力。

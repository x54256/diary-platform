## 维护方式

- 先确定主题和阅读目的，再根据内容独立性决定拆分；短主题可在一份文档分章节说明。
- 功能约定保存业务目标、边界、交互及验收；实现设计保存关键机制、数据、依赖及恢复。
- 每项规则只在所属模块完整定义一次，其他位置引用。
- 接口字段、完整提示词和代码枚举优先引用源码；文档保留它们的含义及设计原因。
- 实际实现与目标规则分别维护，差异必须注明核查依据；迁移文档不等于修改业务行为。
- 已实现、部分实现、保留规划、历史记录等状态按内容核实，不依据文件创建日期判断。

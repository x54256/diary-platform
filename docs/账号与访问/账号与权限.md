# 账号与权限

核对基线：2026-10-29。本文集中说明当前账号功能、访问边界及认证实现，服务于后续开发和维护。

## 1. 功能约定

- 用户以唯一用户名及密码注册，注册成功即返回令牌与用户信息并进入登录态。
- 注册用户名去除首尾空白后不能为空，最多 50 个字符；密码至少 6 个字符。用户名采用当前数据库的字符串唯一规则，未定义不区分大小写的账号合并规则。
- 登录使用用户名与密码；用户名不存在、密码错误均返回 `401` 和“用户名或密码错误”。注册会去除用户名首尾空白，当前登录查询使用请求原值。
- 登录态允许读取当前账号 ID、用户名及创建时间。热词和人物关系见[个人资料](../个人资料/热词与人物关系.md)。
- 普通用户只能读写本人日记、日程、资料及相关业务资源；令牌有效不代表资源 ID 可跨用户访问。
- 未登录访问受保护页面时跳转登录页；登录后回到允许的本地目标路径。
- 退出清除客户端令牌与用户信息。服务端令牌无状态，不维护撤销黑名单；已签发令牌不会因为本地退出而立即失效。
- 当前超级管理员以用户名 `admin` 判定；管理端页面与接口分别校验权限。

密码找回、密码修改、邮箱或手机验证、多因素认证、账号冻结、角色管理与第三方登录不在当前账号功能中。本次文档重组不增加这些能力。

## 2. 登录态与续期

1. 注册或登录成功后，服务端签发 HS256 JWT，`sub` 为用户名，`exp` 默认自签发时起 30 天。
2. 前端将 token 和用户信息保存到 Pinia 与 `localStorage`。
3. 初始化时解析令牌过期时间；过期、无有效载荷或无法解析的令牌清除本地登录态。
4. 请求封装添加 `Authorization: Bearer ...`；服务端解码后按用户名查找现有用户。
5. 每次成功鉴权都会通过响应头 `X-Access-Token` 返回重新延长 30 天的令牌；前端保存该令牌。
6. 请求前发现过期或服务端返回 `401` 时清除登录态并带原路径跳转登录页。

浏览器客户端的过期检查只改善交互，实际令牌签名、有效期与用户存在性由服务端检查。跨域部署必须保留 `X-Access-Token` 的响应头暴露配置，文件上传的 XHR 也读取该续期头。

## 3. 页面与接口权限

用户端认证中间件负责客户端路由跳转；管理端中间件检查已登录且用户名为 `admin`，其他用户进入无权限页。页面中间件在服务端渲染阶段直接返回，业务数据的权限必须由接口保证。

`getSafeRedirect` 只接受以 `/` 开头且不以 `//` 开头的字符串，其他值回到首页。该检查是当前实现边界；以后调整部署 base URL 或跳转规则时，应继续验证本地路径与外部跳转的界限。

后端业务接口使用 `get_current_user`，再根据当前用户查询所属资源。管理端接口通过 `require_admin` 再次检查用户名；隐藏菜单或前端拦截不能替代后端鉴权。未登录/无效令牌返回 `401`；普通用户调用管理员接口返回 `403`。

后端接口在 `/diary/api/auth` 下提供 `register`、`login`、`logout`、`me`。退出接口只返回成功信息，当前前端直接清除本地状态即可完成退出。

密码当前使用 Fernet 对称加密保存，验证时解密比较；它是可逆加密实现，不能在设计文档中写成单向密码哈希。密钥由部署环境提供，文档不记录认证值。JWT 密钥变化会使旧令牌失效；用户更名机制尚未实现，不能假定令牌主体会自动迁移。

## 5. 验收与维护边界

- 新账号注册后直接登录，重复用户名返回 `409`；空白用户名和不合长度的注册字段被拒绝。
- 正确凭据登录成功，错误凭据不暴露“用户不存在”或“密码错误”的区别。
- 缺失、无效、过期令牌及用户已不存在时不能读取受保护资源。
- 成功鉴权响应包含续期头，普通请求及上传流程都能保存新令牌。
- 退出清除客户端缓存，重新打开页面不恢复已清除登录态。
- 访问受保护页面后登录能回到允许路径；无效返回路径回首页。
- 普通用户不能调用管理端接口，也不能通过其他用户的资源 ID 跨用户读取数据。
- 移动端账号输入控件实际字号至少 `16px`，允许页面缩放。

现有认证测试见[后端认证测试](../../backend/tests/test_auth.py)和[前端会话测试](../../frontend/tests/auth-session.test.ts)。本次整理核对了实现，未修改认证代码或执行真实注册、登录请求。

同一令牌在多个并发请求中可收到不同续期结果；前端目前按响应到达顺序保存令牌，未实现最大过期时间比较。退出无撤销、管理员由用户名判定等均为当前明确的实现约束，后续变更须同时更新功能约定与对应测试。

## 2. 核心关系

- 一名用户拥有多篇日记，同一天允许多篇。用户隔离须由查询条件和业务权限共同保证。
- 日记保存当前整理结果，整理结果关联有序事件；原文与结构化内容分别维护修订号。
- 分析结果按轮次保存，`AnalysisItem.scope` 区分日记级与事件级内容。反馈与分析项、继承来源关联。
- 行动项关联日记、生成轮次、来源事件及日程；行动项来源绑定和日程实例联动在行动管理文档维护。
- 收藏指向日记或事件中的一个目标。同一用户对同一目标的唯一性和互斥约束以模型为准。
- 批注绑定目标字段或分析项及文本范围，评论从属于批注；失效、删除和合并去向显式保存。
- 日记、事件分别通过关联表连接标签；标签包含所属用户和业务类型。
- 对话绑定来源类型与来源 ID，消息通过对话关联；新增和发送消息只接受当前支持的来源。
- 转写批次可关联已创建的日记，音频项从属批次；实际创建时机及取消边界见语音录入文档。
- 日程任务定义安排，实例承担具体日期的计划和执行状态；实例保护和墓碑处理由日程服务维护。

## 3. 版本和状态约束

| 字段/机制 | 维护目的 |
|---|---|
| `Diary.is_dirty` | 标识当前原文和既有整理结果的对应关系已发生变化 |
| `Diary.content_revision` | 标识原文与日期来源变化 |
| `DiaryOrganized.source_content_revision` | 记录整理依据的原文版本 |
| `DiaryOrganized.structured_revision` | 标识结构化内容变化 |
| `AnalysisRun.source_structured_revision` | 标识分析依据的整理版本 |
| `AnalysisRun.status` | 区分当前与历史分析轮次 |
| `AnalysisFeedback.is_inherited/source_feedback_id` | 保留反馈继承链 |
| `Diary.deleted_at/deleted_by` | 保留软删除痕迹；允许删除的状态由服务端守卫控制 |
| `DiaryAnnotation.merged_into_id` | 跟踪批注合并去向 |
| 转写词表 ID 与指纹 | 保存任务使用的词表状态 |
| 用途与环节思考配置 | 表达继承与覆盖；任务冻结配置另受任务版本控制 |

字段存在不等于所有调用路径都已执行一致的校验。各模块文档须说明当前校验位置、来源锁、失败恢复及已知差异。

当前日记持久状态为 `saved / organized / analyzed`；语音列表展示状态可由批次派生。前端展示状态不应直接当作数据库枚举。整理任务、图谱运行、语音批次和日程实例各自有独立状态机，见对应模块文档。

## 4. 事务与生命周期

- 创建日记：写入用户、日期和原文，初始为 `saved`；语音路径的提前建记录和后续更新在语音模块说明。
- 整理发布：当前日记结果、结构化事件、检查日志和任务状态须按发布逻辑保持一致。
- 分析发布：普通分析和反馈分析共享轮次模型；应用内通过图谱任务执行，Skill 有独立保存入口，具体覆盖范围见日记管理的双实现对照。
- 修改与删除：服务端检查所有权、日记状态和活动任务；修改修订号与既有来源的对应关系由相关服务维护。
- 对话消息：发送流程在同一请求事务中保存用户消息和模型回复，失败时回滚；上下文所有权的实际校验边界见对话文档。
- 备份恢复：备份包格式、导出范围、预检、清空导入和定时导出规则在备份恢复模块维护。

源文件：

- [模型导入入口](../../backend/models/__init__.py)。
- [启动流程](../../backend/main.py)。

应用启动先检查图谱基础表及事件字段，再调用 `Base.metadata.create_all` 创建缺失的 ORM 表。因此全新数据库也需要先完成适配当前版本的基础结构和扩展准备。

`create_all` 不修改既有字段、索引或约束。SQL 迁移编号记录演进历史；搜索、回顾相关历史迁移仍保留，当前 ORM 已移除对应模块。不能把全部历史文件机械当作当前版本的新库初始化清单，也不能从删除源码推断数据库已删除相应表。

当前仓库没有统一的 SQL 迁移版本登记表。升级方须记录已应用文件、目标数据库和执行结果，核对 SQL 的适用前提及幂等性。图谱专用迁移脚本有自己的清理与写入行为，不能作为通用迁移命令盲目执行。

整理的 LangGraph checkpoint 在 checkpointer 首次初始化时执行 `setup()`，管理其自己的检查点表；它与业务 SQL 迁移分开维护。

数据库排查与读写权限流程遵守 [开发约束](../../AGENTS.md)。本轮文档重组未执行任何数据库连接、SQL 迁移或数据清理。

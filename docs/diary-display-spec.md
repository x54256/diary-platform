# 日记详情页展示细则

> 前端实现参考文档，指导日记详情页（`/diary/[id]`）的布局、交互与数据绑定。

---

## 1. 概述

### 1.1 页面状态

日记详情页根据日记当前状态，呈现两种布局形态：

| 布局形态 | 触发条件 | 说明 |
|---|---|---|
| **单 Tab（日记 Tab）** | 状态为 `已发布` 或 `已整理` | 仅展示日记结构化内容 |
| **双 Tab（日记 Tab + 分析 Tab）** | 状态为 `已分析` | 新增分析 Tab，展示 AI 分析结果 |

### 1.2 状态流转

```
草稿 → 已发布 → 已整理 → 已分析
```

- **草稿**：编辑态，不进入详情页流程
- **已发布**：用户提交原始文本，可查看，可触发"AI 整理"
- **已整理**：AI 整理完成，结构化数据就绪，可触发"AI 分析"
- **已分析**：AI 分析完成，双 Tab 可用

## 2. 日记 Tab 整体布局

从上到下依次排列，所有区块纵向堆叠：

```
┌─────────────────────────────┐
│  NavBar                     │
├─────────────────────────────┤
│  元数据区域                  │
│  (mood · location · tags)   │
├─────────────────────────────┤
│  摘要 (summary)             │
├─────────────────────────────┤
│  引入段 (introduction) [可选]│
├─────────────────────────────┤
│  事件卡片 1                 │
│  事件卡片 2                 │
│  ...                        │
├─────────────────────────────┤
│  琐事 (trivia)      [可选]  │
├─────────────────────────────┤
│  后续计划 (plans)   [可选]  │
├─────────────────────────────┤
│  原始文本           [折叠]  │
└─────────────────────────────┘
```

### 2.1 NavBar

- **标题**：取 `diary_organized.title`
- **无标题时**：显示 `diary_date`（格式如 `2026-07-06`）
- 左侧返回按钮，右侧操作按钮（见第 8 节）

### 2.2 元数据区域

横排展示，各元素以间距分隔，**有值才显示**：

```
[心情]  [地点]  [标签1] [标签2] [标签3] ...
```

| 字段 | 展示方式 | 数据来源 |
|---|---|---|
| 心情（mood） | 文字显示 | 已分析状态 → `diary_analysis.mood`；已整理状态 → `diary_organized.mood`（过渡方案，后续整理阶段不再产出 mood） |
| 地点（location） | 文字显示 | `diary_organized.location` |
| 日记级标签 | 行内小标签，按类型着色 | 从所有事件的 `event_tags` 中去重汇总 |

**日记级标签生成规则**：

- 遍历 `diary_events` 中所有事件的 `event_tags`
- 按标签的 `type` + `name` 组合去重
- 横向排列，按标签类型分别着色（颜色方案见第 7 节）

### 2.3 摘要

- 数据来源：`diary_organized.summary`
- 一段纯文本，直接渲染
- 样式：正文字号，适当行距

### 2.4 引入段（introduction）

- 数据来源：`diary_organized.introduction`
- **可选**：有内容时展示，无内容时不占空间
- 样式：与摘要区分，可用斜体或浅色文字

### 2.5 事件列表

- 一个或多个事件卡片，纵向排列
- 详见第 3 节

### 2.6 琐事（trivia）

- 数据来源：`diary_organized.trivia`
- **可选**：有内容时展示
- 折叠式卡片，默认展开
- 详见第 4 节

### 2.7 后续计划（plans）

- 数据来源：`diary_organized.plans`
- **可选**：有内容时展示
- 折叠式卡片，默认展开
- 详见第 5 节

### 2.8 原始文本

- 数据来源：`diary.raw_text`
- 折叠展示，默认收起
- 标题："原始文本"
- 展开后显示完整原始文本，使用 `pre` 或等宽字体保持原始格式

## 3. 事件卡片设计（核心）

### 3.1 默认状态：收起

```
┌───────────────────────────────────┐
│ ▶ 事件标题                        │
│   [domain标签] [topic标签] ...    │
└───────────────────────────────────┘
```

展示内容：
- **事件标题**：`event.title`
- **事件级标签**：`event.event_tags`，标题下方一行展示，行内小标签样式

### 3.2 展开状态

```
┌───────────────────────────────────┐
│ ▼ 事件标题                        │
│   [domain标签] [topic标签] ...    │
│ ───────────────────────────────── │
│ 事件正文段落 1                    │
│                                   │
│ 事件正文段落 2                    │
│ ───────────────────────────────── │
│ 感受                              │
│ 感受内容...                       │
│ ───────────────────────────────── │
│ 反思与成长                        │
│ 反思内容...                       │
└───────────────────────────────────┘
```

展示内容：

| 区块 | 数据来源 | 是否必选 | 说明 |
|---|---|---|---|
| 事件标题 | `event.title` | 是 | |
| 事件级标签 | `event.event_tags` | 是 | 按 5 类着色 |
| 事件正文 | `event.body` | 是 | 多段落按顺序展示，段落间空行分隔 |
| 感受 | `event.feeling` | 否 | 有内容时显示，小标题"感受" |
| 反思与成长 | `event.reflection` | 否 | 有内容时显示，小标题"反思与成长" |

### 3.3 交互行为

- **点击卡片标题区域**（标题 + 标签所在区域）切换展开/收起
- **默认状态**：收起
- 展开/收起使用折叠箭头图标指示（▶ 收起 / ▼ 展开）
- 过渡动画：可选，建议使用 `max-height` 或 `v-show` + transition

### 3.4 事件正文渲染

- `event.body` 为数组结构时，每个元素为一个段落，按顺序渲染
- 段落间使用适当间距（如 `mb-3`）
- 支持纯文本渲染，无需 Markdown 解析

## 4. 琐事卡片

- **标题**：固定为"琐事"
- **样式**：折叠式卡片，与事件卡片视觉风格统一
- **默认状态**：展开
- **内容格式**：编号列表（`1.` `2.` `3.` ...）

```
┌───────────────────────────────────┐
│ ▼ 琐事                            │
│ ───────────────────────────────── │
│ 1. 琐事内容一                     │
│ 2. 琐事内容二                     │
│ 3. 琐事内容三                     │
└───────────────────────────────────┘
```

---

## 5. 后续计划卡片

- **标题**：固定为"后续计划"
- **样式**：折叠式卡片，与事件卡片视觉风格统一
- **默认状态**：展开
- **内容格式**：编号列表，**按重要性排序**（数据已由后端排好序，前端按数组顺序渲染即可）

```
┌───────────────────────────────────┐
│ ▼ 后续计划                        │
│ ───────────────────────────────── │
│ 1. 最重要的计划                   │
│ 2. 次要计划                       │
│ 3. 一般计划                       │
└───────────────────────────────────┘
```

## 6. 分析 Tab 布局

**仅在日记状态为 `已分析` 时可见。**

从上到下纵向排列，每部分以明确的小标题分隔：

```
┌───────────────────────────────────┐
│  心情（醒目展示）                 │
├───────────────────────────────────┤
│  情绪分析                        │
│  正文内容...                     │
├───────────────────────────────────┤
│  行为与决策分析                   │
│  正文内容...                     │
├───────────────────────────────────┤
│  关注点、需求与自我理解           │
│  正文内容...                     │
├───────────────────────────────────┤
│  认知校准                        │
│  正文内容...                     │
├───────────────────────────────────┤
│  可行动建议                      │
│  正文内容...                     │
└───────────────────────────────────┘
```

### 6.1 各部分详情

| 序号 | 小标题 | 数据来源字段 | 展示说明 |
|---|---|---|---|
| 1 | 心情 | `diary_analysis.mood` | 大字号或醒目样式展示，如"平静 / 专注" |
| 2 | 情绪分析 | `diary_analysis.emotion_analysis` | 小标题 + 正文段落 |
| 3 | 行为与决策分析 | `diary_analysis.behavior_analysis` | 小标题 + 正文段落 |
| 4 | 关注点、需求与自我理解 | `diary_analysis.focus_analysis` | 小标题 + 正文段落 |
| 5 | 认知校准 | `diary_analysis.cognitive_calibration` | 小标题 + 正文段落 |
| 6 | 可行动建议 | `diary_analysis.actionable_suggestions` | 小标题 + 正文段落 |

### 6.2 规则

- **全部只读**，不可编辑
- 每个部分之间使用分割线或卡片间距分隔
- 正文支持多段落渲染
- 事件标签不在分析 Tab 展示，标签展示在日记 Tab 的事件卡片内（见第 3 节）

## 7. 标签颜色方案

5 类标签使用不同颜色区分，统一使用 Tailwind CSS 色值：

| 标签类型 | 含义 | Tailwind 背景色 | Tailwind 文字色 | 示例 |
|---|---|---|---|---|
| `domain` | 领域标签 | `bg-blue-100` | `text-blue-800` | 工作、学习 |
| `topic` | 主题标签 | `bg-green-100` | `text-green-800` | 项目进展、技术探索 |
| `person_object` | 人物/对象标签 | `bg-orange-100` | `text-orange-800` | 张三、某项目 |
| `psychological` | 心理主题标签 | `bg-purple-100` | `text-purple-800` | 焦虑、成就感 |
| `knowledge` | 知识点标签 | `bg-teal-100` | `text-teal-800` | 设计模式、沟通技巧 |

### 7.1 标签样式规范

```html
<span class="inline-block px-2 py-0.5 rounded-full text-xs font-medium bg-blue-100 text-blue-800">
  工作
</span>
```

- 形状：圆角药丸（`rounded-full`）
- 尺寸：`text-xs`，`px-2 py-0.5`
- 背景色浅、文字色深
- 行内展示（`inline-block`），标签间 `mr-1 mb-1`

## 8. 操作按钮

根据日记状态展示不同按钮，按钮位于 NavBar 右侧区域：

| 日记状态 | 可用按钮 | 说明 |
|---|---|---|
| 已发布 | **AI 整理** | 触发整理流程 |
| 已整理 | **编辑** · **AI 分析** · **重新整理** | 编辑跳转编辑页；分析触发分析流程；重新整理触发再次整理 |
| 已分析 | **编辑** · **重新分析** | 日记 Tab 中编辑按钮仍可用，结构化结果可编辑；重新分析触发再次分析 |

### 8.1 按钮样式建议

| 按钮 | 样式 |
|---|---|
| AI 整理 / AI 分析 | 主色按钮（`btn-primary`） |
| 编辑 | 次要按钮（`btn-secondary` / outline） |
| 重新整理 / 重新分析 | 文字按钮或弱化按钮（`btn-ghost` / `text-sm`） |

## 9. 分析进度展示

### 9.1 进度步骤

触发分析后，展示 **3+1** 个步骤的进度：

| 步骤 | 名称 | 说明 |
|---|---|---|
| 1 | 心情与标签提取 | 提取当天心情、生成事件标签 |
| 2 | 核心分析 | 情绪分析、行为分析、关注点分析 |
| 3 | 校准与建议 | 认知校准、可行动建议 |
| +1 | 分析质量检查 | 校验分析结果完整性与一致性 |

### 9.2 实现机制

- **复用现有整理进度的轮询机制**
- 通过 `task_type` 字段区分整理任务和分析任务：
  - `task_type = "organize"` → 整理进度
  - `task_type = "analyze"` → 分析进度
- 轮询接口、进度条组件、状态更新逻辑与整理流程保持一致

## 10. 数据来源说明

### 10.1 日记 Tab 数据映射

| 展示内容 | 数据来源 | 说明 |
|---|---|---|
| 标题 | `diary_organized.title` | |
| 摘要 | `diary_organized.summary` | |
| 地点 | `diary_organized.location` | 整理阶段产出 |
| 心情 | `diary_analysis.mood`（已分析）/ `diary_organized.mood`（已整理） | 分析阶段产出优先；整理阶段为过渡方案 |
| 日记级标签 | 所有事件 `event_tags` 去重汇总 | 前端计算或后端提供 |
| 事件级标签 | `diary_events[].event_tags` | 分析阶段产出 |
| 引入段 | `diary_organized.introduction` | 可选 |
| 事件正文 | `diary_events[]`（body / feeling / reflection） | |
| 琐事 | `diary_organized.trivia` | 可选 |
| 后续计划 | `diary_organized.plans` | 可选，按重要性排序 |
| 原始文本 | `diary.raw_text` | |

### 10.2 分析 Tab 数据映射

| 展示内容 | 数据来源 | 说明 |
|---|---|---|
| 心情 | `diary_analysis.mood` | |
| 情绪分析 | `diary_analysis.emotion_analysis` | |
| 行为与决策分析 | `diary_analysis.behavior_analysis` | |
| 关注点、需求与自我理解 | `diary_analysis.focus_analysis` | |
| 认知校准 | `diary_analysis.cognitive_calibration` | |
| 可行动建议 | `diary_analysis.actionable_suggestions` | |

### 10.3 状态与数据可用性

| 状态 | 可用数据 |
|---|---|
| 已发布 | `diary.raw_text` |
| 已整理 | `diary_organized` + `diary_events`（无 event_tags） |
| 已分析 | `diary_organized` + `diary_events`（含 event_tags）+ `diary_analysis` |

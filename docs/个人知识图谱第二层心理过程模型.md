# 【已废弃】个人知识图谱第二层心理过程模型

> **状态：已废弃**  
> **废弃日期：2026-10-08**  
> 本文档中的第二层定位、术语、数据结构、提取规则和案例均不再作为当前设计依据。正文仅作为历史讨论记录保留，不得据此实现或生成第二层数据。

## 1. 文档目的

本文档记录个人知识图谱第二层“心理过程层”的当前设计，重点统一核心术语的含义和提取边界。

本文档是持续修订的设计草案。

## 2. 第二层的定位

第一层记录人物、事件及其关系，回答“发生了什么”。

第二层以第一层的事件为基础，提取日记记录者在单个事件中的心理过程，回答：

> 我在这次事件中如何认识、体验和调节行动？

第二层只表达该次事件中已经出现的心理活动，不直接形成稳定的个性结论。

## 3. 基本结构

事件与心理过程之间的数量关系为 `1:0..1`：

```text
事件 1 ──具有心理过程──> 0..1 心理过程
```

- 一个事件最多对应一个心理过程。
- 事件中没有明确心理过程时，不建立心理过程。
- 一个心理过程内部包含按事件发展顺序排列的心理过程项。
- 每个心理过程项属于认知过程、情绪与情感过程或意志过程中的一类。
- 不要求每个事件同时具备知、情、意。

```text
心理过程
└── 心理过程项：1..n（按发生顺序排列）
    ├── 序号
    ├── 类型：认知 / 情绪与情感 / 意志
    ├── 内容
    └── 来源要点序号：1..n
```

每条具体心理过程都必须能够定位到来源事件的一个或多个事件要点。

情境、外部行为和事件结果继续保存在第一层事件要点中，不作为心理过程项在第二层重复存储。

## 4. 核心术语

### 4.1 心理过程

#### 心理学定义

心理过程是个体心理活动发生、发展和完成的动态过程，包括认知过程、情绪与情感过程、意志过程。

#### 日记提取定义

心理过程是日记记录者在某个具体事件中明确表现出的认知、情绪与情感或意志活动。

心理过程必须：

1. 属于一个具体事件。
2. 主体是日记记录者。
3. 具有明确的事件要点依据。
4. 保留原内容中的主观归属和确定性程度。

外部事实本身不是记录者的心理过程；记录者对外部事实的感知、理解、判断、情绪体验和行动调节才属于第二层。

### 4.2 认知过程

#### 心理学定义

认知过程是个体获取、保存、加工和使用信息的心理过程，包括感觉、知觉、注意、记忆、思维和想象等。

#### 日记提取定义

认知过程是日记记录者在事件中对信息的感知、注意、回忆、理解、判断、推理、想象或决策。

准入内容包括：

- 明确看到、听到、注意到或得知的信息。
- 明确回忆起的经历或信息。
- 对信息的理解、比较、判断和推理。
- 对方案和结果的设想。
- 对多个选项进行权衡并作出决定。

他人表达的心理内容被记录者感知和理解时，可以作为记录者的认知内容。提取时必须保留信息来源，不将他人的自述改写成记录者的判断。

示例：

```text
原内容：小廖说她最近因为工作感到焦虑。
认知过程：得知小廖自述最近因工作感到焦虑。
```

普通叙事必然隐含的“看到、听到、知道”不自动提取。只有日记明确表达了感知和注意，或该信息继续参与理解、判断、情绪、决策或行动调节时，才进入第二层。

### 4.3 情绪与情感过程

#### 心理学定义

情绪与情感是个体对客观事物是否符合自身需要而产生的主观体验。情绪通常具有较强的情境性和变化性，情感通常与稳定的对象和社会意义相联系。

#### 日记提取定义

情绪与情感过程是日记记录者在具体事件中明确表达的主观体验。

提取时应保留：

- 情绪或情感内容。
- 指向的对象。
- 发生的情境。
- 原内容明确表达的强度和变化。

不根据表情、语气或行为自行推测情绪。“认为某事不好”属于认知评价；只有原内容表达了难过、愤怒、害怕等主观体验时，才提取为情绪与情感过程。

### 4.4 意志过程

#### 心理学定义

意志过程是个体自觉确定目的，根据目的调节行动，并克服困难以实现目的的心理过程。

#### 日记提取定义

意志过程是决策形成后，日记记录者为了实现目标而进行的自我控制、困难克服和持续执行。

决策前的分析、权衡和选择归入认知过程。决策后对行动的调节归入意志过程。

只记录“做了某事”不足以证明存在可提取的意志过程。必须同时具有明确目标，以及自我控制、内外冲突、困难克服或持续执行中的至少一项。

示例：

```text
原内容：我本来想刷视频，但还是把手机放到客厅，继续学习了二十五分钟。
意志过程：为继续学习而移开手机，克制刷视频的冲动并持续学习二十五分钟。
```

### 4.5 心理状态

#### 心理学定义

心理状态是一段时间内心理活动的整体表现，具有一定的持续性，例如专注、分心、紧张和疲惫。

#### 日记提取定义

心理状态用于表达日记记录者在事件的某段时间内所处的整体状态。

心理状态不是与认知、情绪与情感、意志并列的第四种心理过程。它是对某段时间内心理活动的横截面描述：

- 专注、分心主要反映认知状态。
- 紧张、低落主要反映情绪状态。
- 疲惫反映当时的身心状态。

同一内容同时表达情绪和持续状态时，情绪与情感过程记录其体验内容，心理状态只表达原内容明确提及的持续性和整体影响。

## 5. 共同提取原则

1. 只提取日记记录者的心理过程。
2. 每条结果必须能够定位到来源事件要点。
3. 不根据单纯行为推测未明确表达的心理活动。
4. 不将他人的心理活动改写成记录者的心理活动。
5. 他人的表达被记录者感知、理解或判断时，可以成为记录者的认知内容。
6. 不要求每个事件都产生心理过程，也不要求知、情、意同时出现。
7. 保留“认为、推测、可能、不确定”等确定性信息。
8. 第二层只记录单次事件中的心理过程，不生成稳定的需要、动机、价值观、性格或其他个性结论。

## 6. 第一层与第二层的叙述视角

第一层和第二层使用同一份事件内容，但观察中心不同：

| 层级 | 叙述中心 | 回答的问题 |
| --- | --- | --- |
| 第一层 | 事件 | 我经历的事件发生了什么 |
| 第二层 | 我的心理活动 | 我在这次事件中如何认识、体验和调节行动 |

两层都保持日记叙述者的第一人称视角。第二层使用“我感知、我认为、我担心、我克制”等表达，不改成“记录者感知”等第三人称表达。

### 6.1 心理信息覆盖

第二层是对第一层中心理活动信息的分类和重组，不是对整个事件的重复描述。

两层不要求全部信息量相同。第一层还包含外部行为、他人表达、环境、时间和事件结果，其中没有进入我的心理活动的内容不需要在第二层重复。

第二层对第一层中已经表达的心理信息必须满足：

1. **完整**：不遗漏已经明确出现的感知、回忆、理解、判断、预想、情绪体验和意志活动。
2. **忠实**：不改变心理活动的类型、对象、强度和确定性。
3. **无新增**：不补充原内容没有表达的动机、冲突、因果和心理机制。
4. **可追溯**：每条心理过程都能定位到具体事件要点。

“完整”不表示每个事件都要补齐知、情、意。只有原内容明确支持的心理过程才能提取；原内容只有知和情时，意志过程保持为空。

### 6.2 数据分层与组合展示

第一层和第二层不分别存储两份完整事件叙述：

- 第一层事件要点是完整事件内容的唯一知识表达。
- 第二层只保存心理过程项及其来源要点序号。
- 情境、行为和结果不改写后存入第二层。

阅读第二层时，将两层组合成心理视角：

```text
心理视角
= 第一层事件要点
+ 第二层有序心理过程标注
```

组合后的视图保留完整事件的情境、行为和结果，同时标明其中的认知、情绪与情感和意志过程。独立可读性由组合展示实现，不通过重复存储事件叙述实现。

## 7. 案例及已发现的提取问题

### 7.1 来源内容

```text
由于部分问题涉及前端，我将田总拉进了讨论。前端问题讨论结束后，我继续向童姐询问其他问题。继续询问时，我变得非常小心。我担心田总认为我能力太差，觉得我连这么简单的问题都听不明白，还需要继续询问，因此提问时特别小心翼翼。我认为自己可能已经在潜意识中真正把田总当成了领导。
```

### 7.2 第一层事件视角

```text
田总加入讨论后，我继续向童姐询问其他问题。我担心田总认为我能力太差，觉得我连简单问题都听不明白而需要继续询问，因此提问时变得非常小心。我认为自己可能已经在潜意识中真正把田总当成了领导。
```

第一层保留人物、行为、心理表达和行为变化组成的完整事件。

### 7.3 第二层心理活动视角

```text
1. 【认知】我知道田总已经加入讨论。来源要点：[3]
2. 【认知】我设想到田总可能因我继续询问简单问题，而认为我能力太差。来源要点：[4]
3. 【情绪与情感】我担心田总认为我能力太差，觉得我连简单问题都听不明白而需要继续询问。来源要点：[4]
4. 【认知】我认为自己可能已经在潜意识中真正把田总当成了领导。来源要点：[4]
```

该事件没有意志过程的明确依据，因此不生成意志过程项。

“提问时变得很小心”表明担心影响了提问表现，但没有说明我主动克制了某种倾向或有意识地克服了冲突，因此不提取意志过程。

### 7.4 已发现的问题与避免规则

#### 将担心改写成确定判断

错误表达：

```text
我判断田总认为我能力差。
```

该表达将担心的可能情形提高为确定判断。应保留“可能”和“担心”。

#### 使用强度更高的情绪词

“担心”不改写成“害怕”“畏惧”或“不安”。只有来源内容明确表达这些体验时才能提取。

#### 根据行为变化补出意志过程

“提问变得小心”不足以支持“主动克制随意提问”“刻意调整提问方式”或“内心存在冲突”。这些内容必须由来源事件明确表达。

#### 因为避免推断而遗漏认知过程

不能只识别“认为”“判断”等显式词语。感知到田总加入讨论，以及对“田总可能觉得我能力差”这一情形的设想，都是来源内容已经表达的认知过程。

#### 为了完整而强行补齐知、情、意

完整性的对象是来源事件中已经出现的心理信息。当来源内容没有意志过程的明确依据时，意志过程保持为空。

#### 改变第一人称视角

第二层使用“我”表达心理过程，不使用“记录者”等第三人称表达。

# 个人知识图谱分层模型

## 一、设计目标

个人知识图谱以日记中的事实为起点，逐层形成单次事件的中间分析结果、具有证据依据的个性心理碎片，最终形成对个人相对稳定的认识。

各层必须保留与下层事实的证据联系，避免根据单个事件直接形成稳定的个性结论。

## 二、四层结构

### 第一层：事实层

事实层记录日记中已经发生的事实，回答“发生了什么”。

当前包含：

- 人物。
- 事件。
- 人物之间的关系。
- 人物与事件之间的关系。
- 事件之间的关系。

第一层是后续所有心理分析的事实基础。

### 第二层：待重新设计的中间分析层

第二层以第一层的事件事实为基础，为第三层的个性心理碎片提供可追溯的中间分析结果。

当前状态：**待重新设计**。

已废弃的旧方案见[《【已废弃】个人知识图谱第二层心理过程模型》](./个人知识图谱第二层心理过程模型.md)。该文档仅作历史记录，不作为当前设计依据。

### 第三层：个性心理碎片层

个性心理碎片是由具体事件及第二层中间分析结果支持的证据性判断。它能够反映某种个性倾向或个性特征，但尚未经过长期和跨情境验证。

可以形成碎片的内容包括：

- 需要。
- 动机。
- 兴趣。
- 价值观。
- 信念和观念。
- 目标倾向。
- 应对倾向。
- 自我认知。

个性心理碎片必须指向它所依据的事件和第二层中间分析结果。日记中直接表达的价值判断、需要或自我认知，仍然只是该时点的一份个性证据，不直接视为稳定个性。

### 第四层：个性心理层

个性心理层在多个碎片的基础上，形成对个人相对稳定的个性倾向和个性特征的认识。

碎片进入第四层前，必须验证：

1. 是否在不同时间反复出现。
2. 是否跨越多个情境。
3. 是否同时存在语言表达和实际行为的支持。
4. 是否存在相反证据。
5. 是否只针对特定对象或特定压力情境成立。
6. 该倾向是否随时间发生变化。

第四层的结论必须保留适用范围。只在特定情境中反复出现的倾向，不扩大为人物的全局特征。

## 三、层间关系

```text
第一层：事实
    ↓ 从事件中提取
第二层：待重新设计的中间分析层
    ↓ 形成证据性判断
第三层：个性心理碎片
    ↓ 长期、跨情境并结合反例验证
第四层：相对稳定的个性心理
```

上层结论必须能够追溯到下层证据。层级提升表示抽象程度提高，不表示原始事实被替代。

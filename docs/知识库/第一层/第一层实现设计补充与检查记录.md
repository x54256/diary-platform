## 4. 发现并处理的问题

- 将正式要点唯一约束从事件级调整为运行级，保留重新分析的旧证据身份。
- 将正式向量改为必填；未准备完整的结果留在checkpoint。
- 增加关系证据明细及复合外键，防止证据跨事件、跨运行或跨用户错配。
- 为当前运行游标和调用记录增加任务与运行复合归属约束。
- 把普通、反馈两条独立保存路径收口为统一发布；历史任务只在全部日期完成后成功。
- 明确UNKNOWN模型调用的恢复方式，避免承诺进程中断时服务请求零重复。
- 删除正式流程的人工确认和已分析准入旧条款，保留开发人工验收与历史入口的已分析要求。
- 明确旧标签类型knowledge和共享搜索数据不是旧知识库清理对象。

# 召回比较基准

来源：2026-10-26同一冻结历史池的16篇日记、135个当前事件。该批使用最低分0.4、Top5；后续Skill已采用0.4下Top6与全部≥0.5事件的并集，现行规则见[关系实现](../../第一层/关系识别实现.md)。

## 保留内容与用法

| 文件 | 后续用途 |
|---|---|
| [全历史排名](全历史排名.csv) | 25,334对的分数、排名和当时是否被选中；离线比较阈值/Top K选择 |
| [已知事件语料](已知事件语料.json) | 247个事件的冻结正式要点；审阅和语义复核输入 |
| [统计](召回统计.json) | 同一池的参数对照、11处已知遗漏及抽样设计 |
| [审阅参照](审阅参照.json) | 32对分层抽样及4对降阈值新增候选的身份、完整判断、依据和主审采纳；输入按事件ID从语料读取 |

比较新召回策略时，先在相同排名上选候选并统计参照命中与候选量。语义判断需要读取双方全部要点；未审对保持未知。改变要点、向量或计分方法后，应重新冻结输入并重新评估，不能直接沿用旧分数。

## 已确认的诊断结果

- 25,334对中5,652对达到0.4，实际Top5选中671对，其中143对在当时稿件中判有关系。建边比例21.3%不是准确率。
- 已知11处遗漏：8条旧关系、1条用户确认购奶指向、2条盲审发现后由主代理采纳的联系，均被Top5截断。该154条诊断参照偏向已发现关系，不代表全量真值。
- 32对分层样本发现2条联系、30条无关系；降到0.35且保持K5的全部4对新增候选均判无关系。小样本结果不外推阈值以下无正例。
- 阈值0.4下K5/10/15/20/25分别选择671/1310/1903/2411/2873对，命中已知参照143/150/151/153/154条。排名25的购奶指向需要显式补召回，K10仍会遗漏。
- 数据支持优先比较容量和明确指向补召回；事件最大分使多要点事件挤占候选仍是待验证假设。

不承诺重放旧模型或从头重建整次评估。已删除依赖旧运行稿的统计脚本、批次执行文件和重复报告。原始向量不在该基准内；参数候选倍数不能冒充真实费用倍数。

# 知识库验证依据

> 核对日期：2026-11-02。本文维护当前设计结论的最小证据入口和复现边界。证据文件中的个人内容不复制进说明正文；本轮未访问真实数据库、模型或外部服务。

## 1. 如何理解证据

| 证据层次 | 能支持的结论 | 使用边界 |
|---|---|---|
| 工程测试、结构校验与事务回滚 | 指定版本的格式、状态、关联、写入和恢复机制 | 不能据此证明文本忠实、关系语义正确或总体准确率 |
| 冻结来源、人工参照与独立盲审 | 指定样本下的误连、漏判、召回截断及规则边界 | 人工参照不是外部核实真值；同模型双判一致不是准确率 |
| 未参与同轮调参的保留集 | 与开发集分开的固定样本表现 | 小样本不能外推为全量跨日召回率，后续修改须重新核验 |
| 真实发布回执与读回记录 | 指定日期的迁移、保存数量和当次状态 | 不代表后来版本持续通过，数据库状态也可能随后续操作变化 |
| 人工拟议输入输出 | 说明待确认协议及预期规则 | 必须与真实调用分开，不作为已实现或模型通过的证据 |

每个长期结论应在所属功能/实现文档定义一次，并引用此处的来源。历史阈值、Top K、模型或提示词只说明当时条件，当前行为以代码、配置及当前任务冻结版本为准。

## 4. 保留标准与复现边界

材料须有明确开发用途：支撑现行读取、后续方案比较、独有正反例或待确认事项。旧脚本相互引用和历史留痕本身不构成保留理由。后续产生的成功响应、逐轮稿件、临时核验和一次性回执，在有效结论有正式承载后清理。

本次精简针对模块内的验证材料及候选资料。`backend/scripts/fixtures/`、图谱原型及本文3.1至3.4引用的既有来源未改；这些资产的存在不表示所有历史实验可从头重跑。冻结字节码依赖Python3.11，包装器存在不代表源码完整。

日记的[多轮澄清场景](../日记管理/验证材料/多轮澄清场景.md)保留合成输入、模拟回答、期望行为和验证缺口，替代22份试跑流水。[热词候选](../个人资料/候选资料/热词候选-20261027/候选建议.md)保留待确认事项和逐条必要语境，全量只读资料快照已删除。

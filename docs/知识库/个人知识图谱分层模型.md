# 个人知识图谱分层模型

更新日期：2026-10-14。

## 一、设计目标

个人知识图谱以日记中的事实为起点，组织具体情境中的心理过程，提取单次事件中的个性心理碎片，再通过跨事件比较与验证，形成对个人个性心理的认识。

知识图谱首先服务于认识自己，同时帮助解释具体经历中的思考、感受与行动，并为选择提供依据。对个人的认识应保留相对稳定的倾向、适用条件及随时间发生的变化。

各层必须保留与下层事实的证据联系，避免根据单个事件直接形成稳定的个性结论。

## 二、四层结构

### 第一层：事实层

事实层记录日记中已经发生的事实，回答“发生了什么”。

当前包含：

- 人物。
- 事件。
- 人物之间的关系。
- 人物与事件之间的关系。
- 事件之间的关系。

第一层是后续所有心理分析的事实基础。

事件事实包括具体情境、行为、任务表现、结果，以及日记中明确表达的目标、理由和评价。这些内容具有个性分析价值时，可以直接为第三层提供证据，不要求先转换为第二层心理过程。

### 第二层：认知与情感过程层

第二层以第一层的事件事实为基础，描述日记记录者在具体情境中的认知过程和情感过程，为第三层提供本人如何理解、思考和体验的证据。

当前包含两类实体：认知过程、情感过程。一个事件可以包含零到多个过程，过程通过关系定位所属事件及来源要点。

第二层保留事件当时的心理过程和事后反思，按照来源区分时间语境、信息归属和确定程度。

第二层的独立价值是组织单次经历中的心理变化过程，说明在具体情境下如何理解和预期，产生什么情感，怎样权衡、决定、反思或调整。它帮助解释一次经历中“为什么这样想和感受”，并避免上层每次都从原始事件重新组织心理过程。

第二层不作为第一层事实进入第三层的强制通道。行为、任务表现和结果仍由第一层保存；与心理过程直接有关时，第二层可以引用这些事实作为触发条件、反应或结果，无需复制为第二层内容。没有形成认知或情感过程的事件，只要第一层存在充分的个性相关证据，也可以形成第三层碎片。

当前设计见[《个人知识图谱第二层认知与情感过程设计》](第二层/个人知识图谱第二层认知与情感过程设计.md)。旧[《个人知识图谱第二层心理过程模型》](归档/个人知识图谱第二层心理过程模型.md)已废弃，仅作历史记录。

### 第三层：个性心理碎片层

第三层是从单次事件到个性心理分析的中间层，将一次经历中与个性有关的内容整理为可跨事件比较、核验和分析的证据。

个性心理碎片保存来源明确表达的个性相关内容，以及有依据的情境性判断或候选解释，保留其对象、条件和时间范围。单个碎片尚未经过长期和跨情境验证。

第三层需要满足两个要求：

1. 能从单个事件的事实及心理过程中提取。
2. 完整保留来源中与第四层目标分析有关的证据，并明确证据缺口。

#### 提取范围

| 第三层内容 | 回答的问题 | 从单个事件提取的证据 |
| --- | --- | --- |
| 在意与目标 | 这次在追求、保护或避免什么 | 在意的对象、目标、行动理由、取舍、兴趣线索及候选动机解释 |
| 认识与预期 | 如何理解自己、他人和局面 | 判断、信念、预期、原则、自我认识与评价，以及它们如何参与选择 |
| 情境反应 | 在什么情况下产生什么感受、倾向、选择或表现 | 态度、情感、互动、行为、任务表现和结果，以及不同条件下的差异 |
| 应对与调整 | 准备或实际怎样处理，效果如何 | 应对计划、实际行动、心理或行为调整、调节尝试及结果 |

这些内容是提取检查范围，具体产出由事件证据决定。一个事件可以形成零个、一个或多个碎片，不要求覆盖全部内容。

需要、动机、兴趣、价值观、目标、信念、性格、能力、气质和自我意识等传统心理学概念作为辅助标签及第四层分析维度，不作为第三层并列内容类型。标签不能超出碎片证据本身，也不能因标签不同而重复生成内容相同的碎片。

#### 表达句式

第三层采用带有情境和时间边界的事件级陈述，统一句式为：

> 在【本次具体情境】中，我【想到、感到、希望、选择或采取了什么】；【来源明确记录的理由、变化或结果】。

四项内容分别采用以下表达重点：

| 第三层内容 | 表达句式 |
| --- | --- |
| 在意与目标 | 在本次【情境】中，我希望、在意、试图保护或避免【对象】；保留来源明确表达的理由 |
| 认识与预期 | 在本次【情境】中，我认为、预期或评价【具体内容】 |
| 情境反应 | 面对本次【情境】，我产生【感受或倾向】，并出现【选择、行为或变化】 |
| 应对与调整 | 面对【问题】，我计划、尝试或实际采取【方式】；保留来源记录的结果 |

来源记录了什么就表达什么，不要求每个碎片同时包含认识、感受、目标、行为和结果。只有来源明确支持因果关系时，才使用“因为”“因此”等因果连接。表达时保留“可能”“估计”“考虑”“计划”等确定程度，并使用“本次”“当时”“这次”等措辞限定单次经历。

系统提出的解释与来源明确表达的内容分别记录，候选解释句式为：

> 本次【具体表现】，可能涉及【个性心理含义】。

例如，饭局事件的事实性碎片可表述为：

> 本次收到上级领导的聚餐邀请时，我想到应酬会占用个人生活时间、打乱原有安排并耽误遛狗，因此排斥参加；实际参加后抗拒有所减弱，但仍想尽快结束饭局回家。

对应的系统候选解释可表述为：

> 本次对工作应酬的排斥，可能涉及对个人生活自主安排的重视。

#### 证据与表达边界

每个碎片必须保留或通过明确引用取得以下信息：

1. 来源事件及支持它的具体事件要点；使用第二层过程时，定位对应过程。
2. 具体情境、对象、时间语境，以及相关行为和结果。
3. 本人明确表达、本人自我解释和系统分析推断的区别。
4. 判断或解释的依据、确定程度、适用限制及证据缺口。

第三层结合前两层提取。行为、任务表现和结果可以直接提供证据，无需全部转换为第二层心理过程；相关背景继续由下层保存，通过引用取得。

两层分别提供不同性质的输入：

- 第一层提供情境、行为、任务表现、结果，以及来源明确表达的目标、理由和评价。
- 第二层提供认知、情感、权衡、本人原因解释、反思和调节过程。

第三层可以只由其中一层形成，也可以组合两层证据。组合时分别保留事实证据与心理过程证据的来源，不能为了形成统一入口而将第一层事实重复保存到第二层。

本人表达的需要、价值判断、信念或自我认识，是该时点的一份个性证据。本人原因解释保留其解释性质；系统推断须说明证据如何支持判断，不能将候选原因写成已验证的心理机制。

实际行动、尚未实施的计划、调节尝试与实际效果分别表达。普通具体观点保留在第二层；能够提供信念、价值取向或自我认识等证据时，再形成第三层碎片。

“完整依据”要求来源中的相关证据得到保留。某类内容缺乏依据时，保留缺口，不补齐碎片，也不据此形成第四层结论。

### 第四层：个性心理层

第四层在多个事件的碎片基础上，通过比较、查证和修订，形成对个人个性心理的认识。

第四层只以第三层碎片作为直接分析输入，不越过第三层直接汇总第一层事件或第二层过程。需要核验时，沿第三层保存的证据联系回溯下层来源。

#### 内容范围

| 方面 | 内容 |
| --- | --- |
| 个性倾向性 | 需要、动机、兴趣、价值观、目标与理想、信念与观念 |
| 个性心理特征 | 性格、能力、气质 |
| 自我意识与调控 | 自我认识与评价、自我体验、自我调节 |

应对方式和人际互动方式作为上述内容的具体表现参与分析，可以同时涉及需要、信念、性格和自我调节。

#### 表达句式

第四层描述经过多次独立经历检验的长期倾向或有条件的规律，统一句式为：

> 在反复出现的【某类情境】中，我通常或更容易【表现出的倾向或规律】。

句式中的情境条件、倾向强度和适用范围由第三层证据决定。证据只支持特定对象、压力条件或时间阶段时，应将限制写入陈述；存在反例或变化时，应与认识一并保留。

例如，多次独立经历均提供相似证据后，可以形成：

> 当工作应酬明显侵占个人生活安排，且参与对象缺少个人认同时，我通常容易产生排斥并倾向尽快离开。

#### 分析与验证要求

形成第四层认识时，必须检查：

1. 是否在不同时间反复出现。
2. 是否跨越多个情境。
3. 语言表达、实际行为和结果分别提供什么支持，是否存在不一致。
4. 是否存在相反证据。
5. 是否只针对特定对象或特定压力情境成立。
6. 该认识所描述的特点是否随时间发生变化。
7. 现实约束、当时状态或其他解释是否影响判断。
8. 多份材料是否对应独立经历，避免把同一次经历的回忆、转述和反思重复计为独立验证。

第四层的认识必须保留证据范围、适用条件和时间变化。只在特定情境中反复出现的倾向，不扩大为人物的全局特征。

后续日记和用户补充可以用于查证、限定或修订认识。用户对解释的认同作为反馈保存，不自动表示解释已验证。

## 三、层间关系

```text
第一层：情境、行为、任务表现、结果、明确表达
    ├─ 提取认知与情感过程 ─→ 第二层：认知、情感、权衡、反思和调节过程
    │                                      │
    └─ 提供事实证据 ───────────────────────┤
                                           ↓
                         第三层：单次事件中的个性心理碎片
                                           ↓
                         跨事件比较、长期查证、反例核验与修订
                                           ↓
                         第四层：对个性心理的认识，保留适用条件与变化
```

上层结论必须能够追溯到下层证据。层级提升表示抽象程度提高，不表示原始事实被替代。

### 第三层对第四层的支撑条件

第三层提供分析基础，不同内容需要不同证据：

| 分析内容 | 支撑条件与限制 |
| --- | --- |
| 个性倾向性、自我意识与调控 | 结合明确表达、实际选择和后续经历，检查反例、适用情境与变化 |
| 性格 | 比较多次态度与处事表现，区分个人特点和外部约束 |
| 能力 | 必须结合任务、方法、行为与结果，心理过程本身不足以支撑 |
| 气质 | 日记可以提供反应表现，判断还需区分气质、当时状态和情境影响；证据不足时需要补充材料 |

单个事件提供局部证据，多事件积累也需要核验来源质量和情境覆盖。未记录某种表现不能直接作为反例，未找到反例也不能证明反例不存在。日记材料不足以保证对全部个性心理内容形成充分结论。

## 四、当前阶段

第一层已经建立人物、事件及其关系。

第二层已确定认知过程、情感过程及主要关系语义；认知之间关系的属性、共同推导等存储结构及整体验证仍待完成。

第三层确定同时接收第一层事实证据和第二层心理过程证据。第二层保留其解释单次经历的独立职责，不承担转存全部第一层事实的职责。

本文确定第三层与第四层的定位、内容范围及证据支撑要求。第三层的实体粒度、属性、关系和提取核验规则，以及第四层的具体分析模型仍待设计。

后续以真实事件验证第三层内容是否可提取，再结合多个事件检查其能否支持第四层分析，依据验证结果修订模型。

# 事件关系与探索需求

整理日期：2026-10-29。本文保留“让事件联系显性化”的需求、探索目标及有独有价值的历史审阅案例，区分现行三类关系与早期五类方案。第一层的具体生成、审核、存储及恢复协议由对应设计维护。

## 1. 需求目标

事件中的不同内容可以分别支持它与多个其他事件建立联系。标签相同、向量相似或属于一个话题不足以证明真实关系；关系必须有支持两端身份及联系内容的来源依据。

保留的核心目标：

- 以事件为节点，呈现有方向、有证据的直接联系，并可查看来源和详细内容。
- 同一来源事件允许连接多事件，不强行归入单一事项。
- 对象、实际经历者、计划与行动、本人推测与已确认联系分别表达。
- 间接联系通过遍历理解，不把所有传递路径预先写成正式直接边。
- 长期可用于探索与有证据的问答、自我认识；搜索与定期回顾已退出当前实现，其未来消费方式须另行设计。

## 3. 长期保留的判定边界

- 相同对象、目标、问题和事实推进有助于判断直接承接；纯心理反刍或重复叙述不自动构成推进。
- 因果关系需要来源直接支持；时间相邻、主题相似、向量相近均不能代替因果依据。
- 本人明确回忆、参照或比较其他经历时保留引用方向与实际作用；系统发现相似不等同为本人发生联想。
- 计划存在不等于执行。后续记录明确实施、实施失败或重新计划时，分别表达具体状态；没有后续记录不证明未执行。
- 一次经历中的多内容可支撑多条事件级联系，不因每条联系都另建一份同一事件。
- 关系两端都应有可核验依据。证据支持过程正文不等于其事件归属、端点身份和关系类型已同时成立。
- 同一用户内对无序事件对去重并保留方向，不建立来源与目标相同的自环。版本修订后的多轮结果以有效运行和现行唯一约束为准。
- 同名人物、别名、实际对象及代办者需核验，不能把叙述中的参与角色自动作为同一经历者。

## 4. 探索交互目标

当前提供日记内图谱、关系类型筛选、选中节点/关系、内容预览、聚焦事件、邻接展开及返回原图等操作。设计应支持：

1. 清楚展示当前范围、节点身份、关系方向及类型，不能只靠颜色区别。
2. 选中事件或关系后，可查看完整内容、原文确定程度及证据，追溯来源日记。
3. 聚焦、展开和返回的上下文可恢复；空图和筛选无匹配分别有准确提示。
4. 布局变化不导致事件身份或证据错配；触屏操作、文本可读性和点击区域可用。
5. 关系与节点查询始终按用户隔离，展开邻居不能读取其他用户数据。

跨日记列表卡片关系数量、独立图谱列表页、主题或洞察节点等为仍待产品设计的展示方向，不因早期线框存在就写成当前页面。当前实际拖拽、缩放与布局算法由实现说明定义，不继续保留旧“只点按、不拖拽缩放”的限制。

## 5. 旧五类方案的语义参考

下表保留历史审阅中可供重新核验的边界。旧标签仅解释第 6 节案例来源，不是现行正式关系枚举，不建立五类到三类的一一自动映射。

| 历史类型 | 曾讨论的边界 | 独有示例与注意 |
|---|---|---|
| CONTINUATION | 同一事项的事实推进，含计划执行 | 本人看牙与宠物看牙对象不同；计划失败也与未执行不同 |
| CAUSAL | 跨事项的直接引发 | 母亲确诊后的冲击促成本人劝父就医，需保留来源归因 |
| ASSOCIATION | 本人情绪/认知唤起，想起方指向被想起方 | 饭局与第二职业案例的唤起解释曾由用户校验，不等同原文显式表达 |
| THEMATIC | 可命名主题且产生新的呼应/推导 | 单纯复述旧话、弱相关不建立；当前是否表达为关系必须按现行规则重新判定 |
| REFERENCE | 被引用事件作为条件、筹码、时间点、理由或对照承担实质作用 | 离职谈判引用投标进度作为交接时间点；顺带提名称不等于实质引用 |

旧闭环属性、置信度、LOW候选和情绪标签触发算法未成为现行存储要求。其问题价值进入后续研究列表；不能按旧边数量反推当前实现漏边率。

### 6.3 置信度分布与判定难易度结论

- **分布**：26 条边中 HIGH 17 条、MEDIUM 9 条、LOW 0 条。
- **判定难易度**：CONTINUATION（同一事项）判定相对客观，绝大多数为 HIGH；跨事项类型（ASSOCIATION、THEMATIC、REFERENCE 及边界案例）依赖语义理解甚至用户归因，集中在 MEDIUM。MEDIUM 边全部有证据原文与判定依据留痕并直接入图；LOW 判定作为候选写入边表，经人工确认后再入图。


## 7. 待设计与回归问题

- 用户曾提出人物间、人物与事件、洞察间及洞察与事件的联系；属于后续图谱设计范围，不能提前标为已实现。
- 明确提及的联系与没有显式唤起词的联想怎样区分；N25依赖用户补充，机器可靠识别仍需对照验证。
- 同一事件内的回忆/唤起没有独立端点时，保留在正文或注释；其结构与展示方式待定，不为连图虚构事件。
- 执行失败后重试、改约或部分完成如何表达后续链，与行动项/日程状态保持职责分离。
- 用户隔离是当前硬边界；早期跨用户主题洞察属于未确认的另行研究方向，不能据此扩大候选召回或数据访问范围。
- 主题、认知和情感节点在后续层怎样接入，有哪些直接关系和证据结构，按各层设计继续验证。
- 历史N25的弱相似例子说明召回需要检查漏检，但旧0.3575分数与Top5名次来自旧向量，不能复用为当前要点向量的阈值依据；应以最终模型和真实保留样本重放。
- 别名识别、相近标签、实际发生日期与日记日期差异仍需回归；不能根据旧个别数据的空JSON列断言当前标签字段一直为空。

# 个人知识图谱第二层认知与情感过程设计

更新日期：2026-10-09。

本文档记录第二层当前已确定的设计及已审阅样本。实体类型、实体粒度、业务属性和表达规则已确定；事件与认知、情感过程的关系，以及认知与情感关系的判定逻辑和属性已确定；认知之间的三类关系语义与判定边界见第 9.4 节，关系属性及共同推导的存储结构待设计。

## 1. 第二层定位

第二层以第一层事件事实为基础，描述日记记录者在具体情境中的认知过程和情感过程，为第三层的个性心理碎片提供可追溯的中间分析结果。

第一层保存人物、事件及其基础事实关系，事件要点已经包含原文明示的感受、判断和推测。第二层将其中的心理内容组织为具体的认知过程和情感过程，保留其发生情境、经过及证据联系。

第二层同时接收事件当时的心理过程和事后反思。两者按照来源中的时间语境分别表达，事后解释不能改写为事件当时已经存在的认识。

上层结论必须能够追溯到下层证据。单次认知或情感经历不能直接升级为稳定的个性结论。

## 2. 设计推进顺序

按照以下顺序逐步讨论、确定和验证：

0. 阅读实际日记。
1. 确定实体类型。
2. 设计每种实体。
3. 确定关系类型。
4. 设计每种关系。
5. 结合实际日记验证设计。

## 3. 数据来源与主体范围

### 3.1 数据来源

第二层提取以第一层事件要点及其详细内容为数据来源。准入范围沿用第一层：已经完成分析且重要性为“中”或“高”的事件。

每个过程必须能够定位到支持它的事件要点，并通过第一层追溯来源事件原文。

讨论中的批注用于改进表达和核验规则，不作为节点中的事实数据来源。提取结果与事件要点出现事实归属冲突时，应核验第一层来源，不能直接用批注替换节点事实。

### 3.2 主体范围

当前只保存日记记录者本人的认知过程和情感过程。

他人的行为、陈述和解释可以作为本人的认知输入或情感背景，必须保留原有归属。例如，接收他人解释后形成的认识，应说明是谁提供了解释，以及本人如何理解或采纳。

只提取数据来源明确表达的心理内容。个人对自身心理原因的推测，按照个人推测保存，不能改写为已经确定的心理机制。

## 4. 实体类型与粒度

第二层确定两类实体：

1. 认知过程。
2. 情感过程。

一个事件可以对应零到多个认知过程，也可以对应零到多个情感过程。具体数量由实际心理内容决定。

### 4.1 认知过程

认知过程表示日记记录者在具体情境中，接收或回想信息，进行理解、采纳、比较、联想、判断等活动的经过，包括来源明确表达的认识形成、确认或调整。

来源只记录思考经过、没有明确结论时，也可以建立认知过程节点，按已记录内容保存。

一个节点围绕一个具体问题，保存一次连续思考，内部可以包含多个中间判断。不同具体问题或相互独立的思考经历分别建立节点。

节点拆分依据是具体问题与认知活动的边界，不按自然段数量或中间判断数量机械拆分。

### 4.2 情感过程

情感过程表示日记记录者在具体情境中产生、持续或发生变化的情感体验经过。

一个节点保存同一情境下的一段连续情感经历，内部可以包含多种情感及其变化。

过程不要求情感必须发生变化。明确记录了情感的产生和反应，也可以形成节点；有变化时再保留变化。

## 5. 实体业务属性

认知过程和情感过程均保留“主题、过程内容”两项业务属性。证据分别保存在事件与认知过程、事件与情感过程的关系上。

| 属性 | 认知过程 | 情感过程 |
| --- | --- | --- |
| 主题 | 具体情境下，围绕什么问题展开的认知活动 | 具体情境下，针对什么对象产生的情感经历 |
| 过程内容 | 信息从何而来，如何理解、采纳或思考，以及来源明确表达的认识形成或调整 | 面对什么情境，产生什么体验，有什么反应，以及体验如何持续或变化 |

### 5.1 主题

主题应包含足以识别该次过程的具体情境与问题或对象。

例如：

- 中午吃饭时对小廖换座建议的思考过程。
- 田总在场时继续提问的小心与畏惧过程。

### 5.2 过程内容

采用自然、连贯的第一人称叙述，忠实表达数据来源中明确记录的心理经过。

允许借助上下文消解指代、合并信息和调整语序，同时保留信息归属、时间语境及确定程度。上下文整理不得新增缺乏来源支持的心理活动、动机或因果关系。来源支持的联系可以通过明确语句或清楚的上下文识别，不要求固定因果句。多项心理内容同时出现，不代表它们之间存在因果关系；来源仅支持同时存在时，按并列内容表达。

本人在来源中明确表达的推测属于应保留的心理内容，按其原有推测性质保存。原有体验词含义不清时，允许在原词后用括号补充有上下文依据的语境解释，固定标明“结合上下文理解为：……”，使提取者解释与本人表达保持区分。解释仅用于说明原词在该语境中的含义，不补充新的体验、动机、强度或变化，也不作为建立关系的独立证据。

过程内容按实际记录范围保存。日记只记录了部分经过时，不补齐其他阶段。

时间信息直接保留在过程内容中，例如“当时”“回顾此前经历时”“事后想到”。不单独增加发生时间属性。

### 5.3 来源依据

来源依据需要同时明确来源事件及对应要点序号，使读者能够找到支持过程内容的具体证据。

每项事实、心理体验、判断和因果表达均须得到所选要点的支持。选择直接支持过程的必要要点，避免仅因主题相同而扩大证据范围。

认知过程通过“包含认知过程”关系、情感过程通过“包含情感过程”关系追溯证据。关系起点确定来源事件，关系属性“依据要点序号”定位具体证据，不在过程节点上重复保存来源依据。

## 6. 认知过程表达规则

围绕一个具体问题，自然、连贯地描述如何接收、理解和处理信息，以及认识如何形成或调整。按来源保留实际出现的部分，检查是否保留以下内容：

1. 思考起点：外部信息、回想的经历、原有认识、自身体验或遇到的问题。
2. 认知活动：理解、采纳、比较、联想、回忆、质疑、推测、重新审视，以及中间判断和转折。
3. 思考进展或结果：形成、确认或调整的认识，作出的决定，仍然存在的疑问，以及据此考虑的行动。
4. 信息归属：他人提供的解释、本人接受的认识与本人自行推测的结论分别表达。
5. 确定程度：保留“可能”“估计”“我认为”“不能确定”等含义。
6. 时间语境：区分事件当时的认识、回忆中的认识和事后对原因的解释。

这些内容是覆盖检查维度，不是每个节点都必须具备的固定阶段。

根据实际认知活动使用“想到”“理解”“比较”“怀疑”“决定”等措辞，不要求出现“我认为”。表达个人判断、推测或评价时，应明确其归属，并保留来源中的确定程度。

来源只记录判断时，保留判断，不补写形成步骤；来源没有记录结论时，保留已有的探索和疑问。认知过程的识别依据是来源明确表达的心理活动，而非特定句式。

接收、理解和采纳他人信息本身可以构成认知过程，不能一律改写为本人自主推导。只有数据来源支持因果或推导时，才使用“因为”“因此”“由此”等连接。

认知过程中与思考直接有关的情感背景可以保留，使叙述保持完整。

### 6.1 重点内容与加粗规则

以节点主题为依据，优先突出思考所针对的核心问题或现象，以及直接回答该具体问题的关键理解、判断、推测、认识转折、决定或疑问。按内容在过程中的作用选择重点，不将所有认知活动都加粗。

| 优先级 | 内容 | 选择依据 |
| --- | --- | --- |
| 优先加粗 | 被思考、比较或解释的核心问题或现象 | 界定该节点究竟在思考什么；比较或变化是主题时，保留构成该比较或变化的关键状态 |
| 优先加粗 | 理解、判断、推测、转折、决定或疑问 | 直接回答节点主题，或体现围绕该问题的认识进展 |
| 按需加粗 | 输入条件、已有认识、比较或权衡经过 | 直接决定上述认识，或解释认识为什么发生转折 |
| 保留普通正文 | 一般场景、叙事细节、辅助例子或重复表达 | 提供背景和补充说明 |

选择时依次检查：是否界定思考的核心问题或现象；是否直接回答节点主题；是否解释关键认识或转折；是否只是交代场景、列举细节或重复已有意思。情感和行动按其在这段思考中的作用判断。

当情感或行为本身是被分析的对象时，同样属于认知过程的重点。例如，解释工作饭局态度变化时，“起初抗拒—后来接受—现在再次抗拒”共同构成被解释的核心现象，应完整突出关键状态；具体饭局细节按其作用保留。

“去掉后能否理解”用于辅助检查依据是否必要，不单独作为加粗标准。背景内容即使不可缺少，也不必全部突出。

加粗范围取能表达完整意思的最小片段，保留信息主体、确定程度和限制条件。例如“可能与权力有关，但不能确定”应作为完整意思加粗。不按固定字数或比例控制，也不为了覆盖全部过程而将整段加粗。

读者阅读加粗部分，应能辨认该节点在思考什么，以及核心认识或已记录的认知活动；具体背景与完整经过仍由正文提供。不强制每个节点都有结论。

## 7. 情感过程表达规则

围绕“情境与对象、实际体验、反应、持续或变化”组织叙述，检查是否保留来源中明确表达的以下内容：

1. 触发情境或对象，以及与体验直接有关的理解和担忧。
2. 实际情感体验及其原有强度。
3. 身体反应、表达、行为反应和行动倾向。
4. 情感的持续、减弱、增强、转变或调节。

来源没有表达的身体反应、强度、变化或调节不能补写。没有描述变化时，不在正文中附加缺失说明。

评价、实际体验与行动打算需要区分。一般评价不能直接等同于某次情感体验；应对态度和行动打算也不能直接替代情感描述。

对自身情感反应是否合理的反思属于认知内容。例如，“我认为这种畏惧不是很好，没有必要畏惧他”归入反思该反应的认知过程。只有来源明确记录这种反思改变了体验时，才能进一步描述情感变化。

同一次经历可以同时产生认知过程和情感过程。认知过程突出如何理解与判断，情感过程突出体验与反应；共同情境及必要心理内容允许在两类节点中分别保留。

### 7.1 重点内容与加粗规则

以节点主题为依据，优先突出该次情感经历的主要体验、原有强度、持续或变化，以及变化后的残留体验。

| 优先级 | 内容 | 选择依据 |
| --- | --- | --- |
| 优先加粗 | 主要情感及强度、持续或变化、残留体验 | 直接呈现节点主题所描述的情感经历及其进展 |
| 按需加粗 | 身体、表达、行为反应或行动倾向 | 直接体现该情感的强度或状态 |
| 按需加粗 | 触发因素、对象、相关理解或调节过程 | 明确体验针对什么，或解释体验为何产生、持续或改变 |
| 保留普通正文 | 一般背景、叙事细节、辅助例子或重复表达 | 提供背景和补充说明 |

选择时依次检查：是否直接呈现主题中的主要情感与状态；是否解释该体验或变化；是否只是交代场景、列举细节或重复已有意思。触发情境和反应按其作用选择，不全部加粗。

加粗范围取能表达完整意思的最小片段，保留体验主体、原有强度、确定程度和限制条件。例如，抗拒减弱后仍想尽快离开，两部分都应突出，使读者能够准确理解变化后的状态。不按固定字数或比例控制，也不为了覆盖全部经历而将整段加粗。

读者阅读加粗部分，应能辨认该次情感经历的主要体验与已有变化，具体情境与完整经过仍由正文提供。不要求每个节点都有变化，也不补写来源没有记录的反应或调节。

## 8. 通用表达与核验要求

### 8.1 事件归属

提取前，先明确来源事件的核心经历：本人在什么情境中经历了什么、围绕什么展开思考。再判断心理内容是该经历中实际发生的认知或情感，还是叙述中引用的背景、回忆或例证。判断依据是心理内容与当前事件核心经历的关系，不能只按时间新旧或是否出现情感词判断。

作为回忆、比较或解释材料的心理内容，按其作用保留在对应过程正文中。独立建立过程节点时，应确认该心理活动属于当前事件的核心经历。

**提取偏差及原因：**“怀念过去的日子”事件的核心经历是：可能因为于海昕要来，我再次怀念过去，并思考自己为什么怀念。此前看到要点中的“开心”“创造性快乐减少”，就分别建立了情感过程节点，没有先判断这些内容在当前事件中的作用，导致将回忆和比较材料当成了当前事件的独立情感经历。

**本例处理：**保留本次实际产生的“怀念”情感过程；过去完成日记管理平台时的开心，以及过去与现在创造性快乐的比较，保留在反思怀念原因的认知过程正文中。“过去那种上班的快乐可能已经不存在了”属于判断，同样保留在认知过程中。

### 8.2 核验清单

1. 每个过程中的陈述都能得到来源依据支持。
2. 采用连贯的第一人称叙述，保留原有信息主体和时间语境。
3. 不补充来源没有表达的思考步骤、动机、感受、原因或结果。
4. 不加强或弱化原有确定程度、情感强度和评价。
5. 不将未来设想改写为已经发生的心理经历或行动。
6. 不将事后自我解释改写为已验证的心理机制。
7. 提取检查意见不进入节点正文，例如“原文没有记录是否缓解”属于核验说明。
8. 对一般评价与情感体验难以区分的内容，不强行补出具体情绪名称或独立情感过程。
9. 检查来源中明确表达、属于当前主体范围的认知和情感内容是否得到覆盖；每个过程应保留理解其经过所必需的背景、中间判断、转折和结果。
10. 检查独立节点中的心理活动是否属于来源事件的核心经历，以及回忆、比较或例证材料是否按其作用保留。

## 9. 关系设计

### 9.1 包含认知过程

| 项目 | 定义 |
| --- | --- |
| 关系名称 | 包含认知过程 |
| 起点 | 事件 |
| 终点 | 认知过程 |
| 含义 | 认知过程属于该事件核心经历中，本人实际进行的一段认知活动 |
| 数量约束 | 一个事件包含零到多个认知过程；当前每个认知过程节点归属一个事件 |
| 业务属性 | 依据要点序号 |

关系固定方向为“事件 → 包含认知过程 → 认知过程”，可以自然读作“该事件包含该认知过程”。

**依据要点序号：**整数数组，记录起点事件中直接支持过程内容及其事件归属的要点序号，例如 `[1, 2]`。数组至少包含一个有效序号，序号不得重复，均须存在于起点事件的要点中。起点已确定事件身份，不在关系属性中重复保存事件 ID。

认知节点保留主题和过程内容；关系保留事件归属及具体证据。每项事实、判断、推测和因果表达均须得到所选要点的支持。

建立关系时，先确认认知活动属于来源事件的核心经历，再选择证据要点。认知过程中提及的其他事件可以作为输入或回忆材料；仅被提及不构成归属，不能为了保存证据而建立“包含认知过程”关系。事后反思与历史经历应按照各自的事件语境判断归属。

关系 ID、起点、类型和终点是存储所需的结构字段，不属于业务属性。

**示例：**“江西项目数据梳理与需求讨论” → 包含认知过程 → “查看江西数据并沟通需求时，对数据清晰度的判断过程”；关系的依据要点序号为 `[1, 2]`。

### 9.2 包含情感过程

| 项目 | 定义 |
| --- | --- |
| 关系名称 | 包含情感过程 |
| 起点 | 事件 |
| 终点 | 情感过程 |
| 含义 | 情感过程属于该事件核心经历中，本人实际经历的一段情感体验 |
| 数量约束 | 一个事件包含零到多个情感过程；当前每个情感过程节点归属一个事件 |
| 业务属性 | 依据要点序号 |

关系固定方向为“事件 → 包含情感过程 → 情感过程”，可以自然读作“该事件包含该情感过程”。

**依据要点序号：**整数数组，记录起点事件中直接支持情感内容及其事件归属的要点序号。数组至少包含一个有效序号，序号不得重复，均须存在于起点事件的要点中。起点已确定事件身份，不在关系属性中重复保存事件 ID。

情感节点保留主题和过程内容；关系保留事件归属及具体证据。体验、强度、反应、变化和因果表达均须得到所选要点的支持。

建立关系时，先确认体验属于当前事件的核心经历，再选择证据要点。作为回忆、比较或解释材料出现的其他经历中的情感，不建立当前事件的包含关系。该关系表达经历归属，情感的具体触发或变化原因按来源在过程正文中表达。

关系 ID、起点、类型和终点是存储所需的结构字段，不属于业务属性。

**已核验对应：**

| 事件 | 情感过程 | 依据要点序号 |
| --- | --- | --- |
| 江西项目数据梳理与需求讨论 | 田总在场时继续提问的小心与畏惧 | `[3, 4, 6]` |
| 晚上与于海昕等人的聚餐应酬 | 从收到邀请到参加饭局，排斥与抗拒减弱 | `[1, 2, 3]` |
| 怀念过去的日子 | 本次再次怀念过去同事与工作生活 | `[1, 2]` |

两类包含关系在 HTML 中均以“关系依据”展示对应事件要点，不在“关系属性”中重复显示依据要点序号。

### 9.3 认知与情感之间的关系判定逻辑

关系判断依据来源明确语句及清楚的上下文联系。先确认两端过程的实际内容、时间和对象，再判断联系的方向、类型及涉及的具体内容和阶段。心理学理论帮助识别关系类型，具体连边仍须得到事件要点及必要的原文核验支持。

#### 9.3.1 关系语义

| 关系 | 方向 | 判定依据 |
| --- | --- | --- |
| 引发情感 | 认知过程 → 情感过程 | 某种理解、评价、判断或预期与该情感的产生之间有明确语句或清楚的上下文联系 |
| 调节情感 | 认知过程 → 情感过程 | 来源记录了本人借助认知活动调整或尝试调整情感体验、表达的过程；尝试与效果分别按来源判断 |
| 影响认知 | 情感过程 → 认知过程 | 情感影响了注意、回忆、理解、判断、选择或应对思考，联系得到来源支持 |
| 反思情感 | 认知过程 → 情感过程 | 认知活动以该段情感为对象，分析原因、评价是否合理或理解其意义 |

##### 引发情感

**定义：** 本人对情境的理解、评价、判断或预期，参与了某段情感体验的产生。方向表示认知对情感的作用。

**成立条件：** 能指出具体认识及其对应的情感体验，来源明确表述或清楚的上下文支持该认识与情感产生之间的联系。关系描述说明“怎样的认识使我产生了什么感受”。

**区分标准：** 事件中出现了某条信息与某种情绪，不足以证明认知引发情感；须有本人接收、理解或评价信息的认知内容及两者的联系。事后推测自己为何有这种感受，优先判断为反思情感，不能将分析过程直接当成此前情感的起因。

**当前样本：** 我想到应酬会占用个人时间、打乱原有安排并使人疲惫，因此在聚餐前排斥参加饭局。

##### 调节情感

**定义：** 本人借助思考、重新理解、自我提醒或调整注意等认知活动，调整或尝试调整已有或预期的情感体验、表达。方向表示认知对情感的调节作用。

**成立条件：** 来源支持具体认知活动具有调整情感的目的或功能，并能定位它针对的情感。可以记录明确的调节尝试，也可以记录重新理解与情感变化之间清楚的联系；不要求出现“调节”这个词，不补写来源没有记录的调节意图。

**尝试与效果：** 已记录实际调节尝试，即使未记录效果或明确表示没有效果，也可建立关系。关系描述只写已有尝试与效果；仅表达想要调节的愿望、尚未进行的计划，不作为已经发生的调节过程。来源记录体验改变时，按实际方向表达减弱、增强、维持或转变，不将调节统一理解为减轻负面情绪。

**区分标准：** 分析原因、评价反应是否合理，属于反思；实际借助某种思考调整感受，才支持调节。仅记录情绪后来减弱或改变，没有说明与认知活动的联系，不能判定调节。纯行为或身体活动引起的变化，须另行核验是否有对应的认知过程，不能直接填入这类关系。

**表达示例（用于说明规则，不是当前日记事实）：** 我提醒自己对方只是提出修改意见，并不等于否定我的能力，想借此缓解紧张，但仍然感到紧张。这支持调节尝试，不支持已经缓解。

**当前样本：** “没有必要畏惧田总”记录了评价；“实际吃饭时没有那么抗拒”记录了变化，两者都没有清楚记录相应的认知调节过程。过去把饭局当成蹭饭机会属于历史回顾，不能连接成本次抗拒的调节原因。当前数据没有调节情感实例，类型保留供有来源支持的样本使用。

##### 影响认知

**定义：** 某段情感体验影响了本人关注什么、回忆什么、如何理解或判断，以及如何选择、考虑应对。方向表示情感对认知的作用。

**成立条件：** 来源支持具体情感与某段认知活动之间的影响联系，能说明“在什么感受下，我的哪段思考受到怎样的影响”。应对内容须包含判断、选择或思考，不能仅凭后续行动建立认知关系。

**区分标准：** 情感与思考先后出现不等于前者影响后者。思考以分析情感本身为对象时，判断为反思；情感参与了对其他问题的注意、判断或应对思考时，判断为影响认知。描述只覆盖受到影响的内容，不将整个认知过程都归因于该情感。

**当前样本：** 在觉得公司的裁员与降本安排“很没意思”的情绪下，我考虑被辞退时不主动离职、要求补偿，必要时找律师。关系针对这段应对思考，不覆盖此前为了上海户口而耗下去的考虑。

##### 反思情感

**定义：** 本人以自己的某段情感体验为思考对象，分析它的原因、变化、合理性或意义。方向表示认知活动所反思的情感对象。

**成立条件：** 来源记录了针对具体情感的分析、比较、解释或评价，能说明“我在思考这段感受的什么问题”。只有情感词或对情境的一般评价，不能替代反思过程。

**区分标准：** 反思关系不表示这段思考造成了被反思的情感，也不自动表示思考改变了情感。本人提出的原因解释保留其推测性质。关系方向由认知指向情感，是对象联系，不是发生顺序或因果方向。

**当前样本：** 我回顾参加工作饭局的态度变化，认为当前重新抗拒可能与公司和熟悉的人已经不同于过去、饭局没有以前那么有意思有关。

##### 关系并存的判定

同一对过程可以有多类关系，但每类都须有对应的事实依据。例如，来源同时记录了分析紧张原因和借助重新理解尝试缓解紧张，可以分别建立反思情感与调节情感。不能由一类关系自动补出另一类，也不为增加关系数量重复表达同一个联系。

认知与情感关系使用以下属性：

| 属性 | 定位与内容 |
| --- | --- |
| 关系描述 | 与事件之间的关系描述定位一致，用自然语言说明两端过程如何联系；在句子中交代具体对象、内容和阶段 |
| 关系依据 | 非空引用数组，每项包含事件ID及非空、不重复的要点序号数组，定位支持关系成立及描述内容的来源 |

关系描述遵循以下规则：

1. 描述具体联系，与关系类型、方向和依据一致。每项关键事实须能在引用的事件要点中定位，必要时核验原文。
2. 采用自然的第一人称叙述，说明哪些认识引发或调节了什么体验、什么体验影响了哪段思考，或本人如何反思该体验。
3. 一条关系只涉及过程中的部分内容或阶段时，直接在句子中写清楚，例如“在聚餐前排斥参加饭局”。
4. 保留来源中的“可能”“推测”“不能确定”等表达；调节尝试与调节效果分别按来源表达。
5. 抽取和审核规则写在设计文档中，不混入实例关系描述。描述不重复整段过程内容。

示例：我想到应酬会占用个人时间、打乱原有安排并使人疲惫，因此在聚餐前排斥参加饭局。

原“作用范围”属性统一改为“关系描述”，其对象与阶段的限定要求融入描述正文。

#### 9.3.2 上下文与关系涉及的内容、阶段

1. 不要求出现“因为”“所以”等固定句式。围绕同一对象展开的理由说明、对照、转折或明确承接，可以支持关系判定；仅时间相邻、属于同一事件或主题相似不能作为连边依据。
2. 不将情感词机械限定为固定类别。担忧、排斥、小心、想离开等内容，应结合体验与反应的联系理解；不能只因部分内容呈现为行为或行动倾向而排除情感联系。
3. 每条关系须明确作用对象和阶段。只支持聚餐前排斥的认识，不能扩展为解释参加后抗拒减弱；过去的调节经历不能自动连接为本次体验的调节原因。
4. 反思情感与受情感影响的应对思考分开判断。分析“为什么有这种感受”属于反思；在这种体验下考虑“接下来怎么办”属于影响认知。后者的关联仍须得到来源支持。
5. 调节尝试与调节效果分开判断。评价“没有必要畏惧”本身不等于实施了调节，也不等于畏惧已经减弱。
6. 关系依据须支持两端之间的联系，不能仅复制两个节点各自的依据。回看原文发现第一层要点遗漏或改变联系时，先核验和修正第一层，不将批注作为事实证据。
7. 本人提出的原因推测按推测性质表达，不改写为已确定的作用。事后分析一种情感的原因，属于反思，不能直接将这次反思连成此前情感的起因。

#### 9.3.3 多个认知与同一情感

允许多个认知过程关联同一情感过程。认知节点按具体问题和连续思考边界划分，不为了形成一对一关系而合并。

多个认知分别有依据关联同一情感时，可以分别建立关系；来源明确表达多个认识共同参与情感形成时，须保留共同作用的含义，不把每个认识都写成独立、充分的原因。共同作用的具体存储结构待关系属性设计时确定。

多项信息先后出现，不足以证明它们共同引发情感。认知与情感之间使用引发、影响或调节语义；认识之间的逻辑推导另行设计。

#### 9.3.4 实例与判定边界

- 江西讨论中，“害怕田总觉得我太菜……所以问得特别小心翼翼”支持负面评价预期与担忧、小心反应的联系。关系不能扩展为解释全部关于领导权力的畏惧。
- 聚餐前表达排斥，紧接着说明应酬占用生活时间、打破安排等理由，清楚的上下文支持这些认识与排斥的联系，不能仅按“因为”所在句子的语法对象割裂判断。
- 谈到亏损、可能继续裁员和 AI 提效裁员后，“哎呀，反正我觉得很没意思”支持提取情感体验。可表达为“很没意思（结合上下文理解为：对公司围绕降本裁员的这些安排感到厌倦，觉得这样的工作处境缺少意义）”，括号内容是语境解释。
- 从“觉得很没意思”承接到“想裁那就裁吧”，再考虑补偿、不主动离职及找律师，支持情感影响后续应对思考。作用范围限定为该段应对态度与思考，不涵盖此前为了上海户口而耗下去的考虑，也不表示全部应对决定都由情感造成。
- 对“很没意思”最直接的来源语境是公司亏损、可能继续裁员及 AI 提效裁员。童春秀纠纷和降薪虽在此前叙述中出现，不能仅凭同属饭局就确定它们共同造成该体验。

### 9.4 认知过程之间的关系类型

认知之间的关系用于记录本人实际发生的思考联系。当前采用推导认知、修正认知、引出思考三类语义，按以下规则审阅实际样本。类型命名与适用边界属于本项目的设计，不是心理学已有的统一分类。

#### 9.4.1 类型定义与方向

| 类型 | 方向 | 定义与成立条件 |
| --- | --- | --- |
| 推导认知 | 提供推理依据的认知过程 → 使用依据形成新认识的认知过程 | 一个或多个过程中的认识，被本人用于另一过程的推理并形成新认识；日记须记录依据与推理联系，保留推测及确定程度 |
| 修正认知 | 进行修正的认知过程 → 被修正的原认知过程 | 新的思考实际改变了此前认识，包括纠正判断、限定适用条件或放弃原判断；须能定位原认识及其改变 |
| 引出思考 | 引出另一段思考的认知过程 → 被引出的认知过程 | 一段认知使本人联想到另一个问题，或开始另一段思考；日记须记录这种引出联系，不要求构成逻辑推导 |

修正认知的方向表示修改对象，不表示旧认识先于新认识的时间顺序。推导认知不限定为严格演绎；日记记录的预测、归纳或基于理由的推测，只要有实际推理联系，也按来源性质表达。

#### 9.4.2 判定边界

1. **先核验节点边界。** 节点是一段围绕具体问题的连续认知过程，内部的依据、思考和结论保留在过程内容中。关系用于连接按现有边界独立成立的过程，不为了展示推理链而将同一次过程机械拆成前提节点、思考节点、结论节点。
2. **联系须来自日记。** 不要求固定的“因为”“所以”句式，但须有明确表述或清楚的上下文支持本人确实使用、改变了某项认识，或由其引出另一段思考。分析者能够推出一个结论，不等于日记记录者进行过这次推理。
3. **推导与引出分开。** 源过程中的认识实际承担了目标过程的推理依据，判断为推导；只促使本人想到另一个问题，尚无依据到结论的推理联系，判断为引出思考。同属一个事件、主题相近或叙述相邻不能单独证明任一关系。
4. **修正须有实际改变。** 只有疑问、冲突或反对意见，尚未改变原认识时，不作为已经发生的修正。仅比较两种判断，也不自动表示其中一种被修正。
5. **指明具体内容。** 关系描述须说明源过程中的哪项认识与目标过程中的哪段思考相关，不能把两个完整过程的全部内容都视为存在同一种联系。关系属性与证据结构另行设计。
6. **不自动补全链路。** 已有认知与情感关系，不据此自动生成认知之间的关系；直接连边须有对应的具体联系依据。认知与情感关系同样不因认知之间建立了关系而自动新增。

支持与质疑作为后续候选类型：支持涉及加强原判断，质疑涉及动摇原判断。它们分别与形成新认识的推导、已经改变原认识的修正存在区别；当前不纳入三类关系，待实际样本验证是否需要独立类型。

#### 9.4.3 多个认知共同推导

**成立条件：** 来源明确表述或清楚的上下文支持本人实际使用一个或多个认知过程中的认识作为依据，形成另一过程中的新判断。须能定位参与依据、形成的认识及推理方向；主题相近、分析者能概括共同点，不足以建立推导关系。

**讨论案例（由用户提供，用于设计验证，不作为当前日记事实）：**

- A：双方父母见面前，各自先与自己的父母确认问题，以降低风险，将重要事情的发展掌握在自己手中。
- B：乘飞机时带一个空瓶，安检后接水，避免上飞机后没有水喝而口渴。
- C：重要事情的发展掌握在自己手中，要控制风险。

A、B 是具体情境中的应对认识，C 是更一般的原则。若本人回顾 A、B 并由此概括 C，可以建立 `A＋B → C`，方式为共同归纳；若先有 C，再用它分析具体问题并形成 A、B，则方向为 `C → A`、`C → B`，方式为原则应用。仅分别列出 A、B、C，不能确定实际发生了哪个方向的推导。

共同归纳时，只能使用案例实际支持的内容。A、B 最明确的共同点是提前准备、控制可预见风险；“重要事情的发展掌握在自己手中”更直接对应 A，不能自动将 C 的全部含义都归给两个案例。

##### 共同推导与独立推导的表示

当日记记录 A、B 共同参与形成 C 时，图谱用一个中间的“推导关系节点”表示一次共同推导：

```text
A ─┐
   ├→ ◇ 推导① → C
B ─┘
```

推导关系节点表示一次联系，统一记录关系描述和来源依据；不另写一份认知过程正文。A、B 是该次推导的参与依据，C 是包含所形成认识的认知过程。它不是收集所有相似认知的容器。

若来源分别记录 A、B 各自独立推导 C，则分别建立 `A → 推导认知 → C`、`B → 推导认知 → C`。共同参与不能被解释成各自独立成立，也不要求 A、B 之间存在推导关系。

HTML 展示方案：认知过程保持圆形，中间的推导关系用较小菱形表示；参与依据指向菱形，菱形指向目标认知。点击菱形查看参与认知、目标认知、关系描述和依据。双击查看关联时，将该次共同推导作为完整单元展示，包含全部参与项，避免只显示一项依据。具体存储字段及 HTML 实现尚未完成。

##### 后续补充认知与重复结论

每次推导按自己的来源确定参与项，不按时间累积，也不因新认知与主题相关就自动接入。

| 情况 | 处理 |
| --- | --- |
| 补充来源说明同一次推导还使用了 D | 将 D 加入原推导，表达 `A＋B＋D → 推导① → C` |
| 后来实际又进行了一次推导 | 记录新推导，保留原推导及其依据 |
| 后续推导使用 A、B、E，未使用 D | 新推导只连接 A、B、E，不能继承 D |
| D 只是主题相近 | 不作为推导参与依据 |

**用户进一步提出的情况：** `A＋B＋D → C`，后来 `A＋B＋E → F`，而 F 与 C 的结论内容本质相同。

```text
A＋B＋D → ◇ 推导① → C
A＋B＋E → ◇ 推导② → F
```

当前节点表示完整认知过程。两次实际发生的认知过程即使形成相同结论，也分别保留 C、F，并保存各自使用的依据。不能因结论相同，将两次推导合成 `A＋B＋D＋E → C`；这会虚构一次使用全部依据的共同推导。

HTML 可按相同结论分组展示 C、F，展开后查看各自过程和依据；分组属于展示方案，不合并原始节点，结论是否相同仍须核验适用对象、条件和确定程度。若以后需要让不同推导共同指向一个结论实体，则须单独设计“认识／结论”实体及其与认知过程的关系，当前不据此新增实体。

#### 9.4.4 案例：担心被评价与反思畏惧

**来源：** 江西项目数据梳理与需求讨论，`event-jiangxi` 要点 4、5、6。

| 角色 | 当前节点 | 内容定位 |
| --- | --- | --- |
| 认知 A | `process-jiangxi-evaluation`：田总在场时，对继续提问会如何被他评价的思考过程 | 担心继续提问会被田总评价为能力差 |
| 情感 E | `process-jiangxi-fear`：田总在场时继续提问的小心与畏惧过程 | 担忧、畏惧与提问时的小心体验；A 的引发联系只覆盖负面评价预期对应的部分 |
| 认知 B | `process-jiangxi-reflection`：回顾需求讨论经历，反思自己为何畏惧田总的认知过程 | 分析本次小心与畏惧的原因及合理性，保留本人的推测性质 |

**当前处理：** 保留 `A → 引发情感 → E ← 反思情感 ← B`，暂不建立 A 与 B 之间的直接关系。

这表示认知 A、认知 B 分别与同一个情感 E 直接连接，两个认知通过 E 间接关联。其含义是两段认知围绕同一情感体验存在联系，不表示 A、B 之间已经发生推导或修正，也不表示 A 引发 E 后，E 又必然促成 B。

若来源另外支持畏惧促使本人开始反思，可以独立判断 `E → 影响认知 → B`；仅因 B 反思了 E，不能自动补出这条关系。已有间接路径也不妨碍来源支持的认知直接关系成立，须逐条核验。


B 的分析对象是自己的情感反应。来源没有清楚记录 B 使用 A 的判断进行推导、修正 A，或由 A 的思考内容直接引出 B；认知与情感的两条关系已经表达两段认知围绕同一体验的联系。这个结构不是因果链，不能据此声称 E 已被证明促成了 B。

**直接关系成立的对照示例（仅说明规则，不是本次日记事实）：** “想到自己担心他评价我的能力，我开始追问，为什么如此在意他的评价？”此处 A 的思考内容直接引出了 B，可以建立 `A → 引出思考 → B`。

本案例的核验重点是认知之间是否有实际的直接联系，而非图上是否已经存在间接路径。即使经情感节点相连，来源另外支持直接联系时，仍可按对应类型建立关系。

#### 9.4.5 案例：不同日记中的聚餐排斥与明确参照

**案例来源：** 用户在设计讨论中提供的跨日记情境，用于验证关系边界；宁宣相关记录尚未核验实际日记，不据此新增实例节点或关系。

前一次日记记录参加于总饭局时的排斥。另一次记录学姐宁宣来了，自己主动约饭，但约完后想到会排斥聚餐。用户进一步补充，后一次记录中明确提及：“就像之前和于总吃饭一样有点排斥”。

##### 未提及此前经历时

两次记录都出现聚餐相关的排斥，只能直接确认体验相似。被邀请与主动邀请的情境不同，排斥的对象、相关认识和原因须分别依据日记判断；不能仅凭相同的情感词，将两段认知连接为推导或修正，也不能概括为本人排斥所有聚餐。

可以通过主题检索或关联阅读并列查看两次经历，帮助比较反复出现的体验。系统识别的相似性不作为本人实际进行比较、推理或修正的事实。

##### 明确提及此前经历时

“就像之前和于总吃饭一样有点排斥”记录了本人主动回忆并比较两次体验，已具有明确的跨事件联系。核验两端事件及来源要点后，可以建立：

```text
本次与宁宣约饭的事件 → 提及事件 → 此前与于总吃饭的事件
```

**关系描述示例：** 约完宁宣后，我想到自己有些排斥，并将这种感受与此前和于总吃饭时的排斥作比较。

这段回忆与比较保留在当前过程正文中。该句首先支持情感体验的比较，尚未说明本人使用此前认识形成新判断，或改变了原判断；当前不新增认知之间的直接关系，也不据此新增情感比较关系类型。

##### 认知参照的候选边界

“参照认知”表示当前思考明确调用此前某项认识进行比较，尚未形成推导或修正。直接关联过程节点能定位当前思考使用了哪段旧认识，但这一使用需求须通过实际样本验证。

若后续考虑纳入，至少须满足以下条件：

1. 两端均为可独立成立的认知过程，被参照的是具体认识或思考内容。
2. 日记明确表述或清楚的上下文支持本人实际进行了参照，不能仅由系统发现内容相似。
3. 关系描述能够指出参照的具体内容，而非只有“想到以前”。
4. 来源记录旧认识作为理由参与形成新判断时，优先判断推导；记录实际改变原判断时，判断修正。参照不能用于替代已能明确表达的推导或修正联系。

例如，“这次也像上次一样，想到聚餐会占用自己的时间”指向认知内容；“这次也像上次一样排斥”指向情感体验。内容出现在认知节点正文中，不意味着其中每个被引用对象都属于认知。

**当前决定：** “参照认知”保留为候选，不纳入正式关系类型。该案例先用过程正文及已有事件提及关系表达；不能把“暂不纳入关系类型”解释为两次经历之间没有联系。

##### 进一步形成认识时

若本人实际比较两次经历，继续形成“对聚餐的排斥并不只出现在工作应酬中”等新认识，可以核验参与依据及新认知过程，判断共同推导。若前一次确有“只排斥工作应酬”的判断，后一次实际改变该判断，可以判断修正。原记录只有排斥体验时，不能补造“只排斥工作应酬”的旧认识。

## 11. 理论参考与使用方式

以下资料用于建立表达与核验框架，节点事实仍以第一层事件要点为依据。节点属性、关系及证据存放方式属于本项目的设计决定。

- [APA：认知过程](https://dictionary.apa.org/cognitive-process)：认知包含知识的获取、储存、解释、处理、转换和使用，支持将接收与采纳信息纳入认知过程。
- [APA：情绪](https://www.apa.org/topics/topicemotion.html)：情绪涉及体验、行为与生理成分，支持在来源明确时保留体验及反应。
- [Gross（1998）：情绪调节过程模型](https://journals.sagepub.com/doi/abs/10.1037/1089-2680.2.3.271)：讨论情境、注意、认知变化和反应调节，作为检查情感经过的参考。
- [Gross（2015）：情绪调节的现状与展望](https://doi.org/10.1080/1047840X.2014.940781)：调节涉及影响情绪过程的目标、策略及实施，支持区分调节尝试与实际效果。
- [APA：态度](https://dictionary.apa.org/attitude)：态度是对对象的总体评价，用于帮助区分评价与具体情感体验。
- [Nisbett 与 Wilson（1977）：心理过程的言语报告](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Social_Cognition/Nisbett_Wilson_1977_Telling_more_than_we_can_know.pdf)：提醒区分事后原因解释与对当时心理活动的报告，保留来源中的推测性质。

- [Chesñevar 等：论证交换模型](https://www.mit.edu/~irahwan/docs/KER2006.pdf)：区分信息、推理应用和结论，作为区分推理联系及多项依据共同推导的参考；本项目节点仍采用完整认知过程。
- [Alchourrón、Gärdenfors 与 Makinson（1985）：信念修正](https://fitelson.org/piksi/piksi_22/agm.pdf)：讨论认识的增加、撤回与修正，作为检查原认识是否实际改变的参考。
- [Anderson（1983）：记忆的激活扩散理论](https://www.sciencedirect.com/science/article/pii/S0022537183902013)：讨论关联网络中的记忆提取，为区分联想唤起与逻辑推理提供参考；引出思考的项目定义还包括来源明确记录的后续问题思考。

# 阶段六：数据飞轮闭环详细设计

> 对应范围：全平台数据沉淀与反哺机制

## 1. 阶段目标

阶段六要把日记内容、日记详情对话、回顾对话和 AI 伙伴对话统一沉淀到人物画像、心路历程和认知洞察，让平台随使用持续理解用户。

---

## 2. 数据闭环与更新机制

整个平台形成**数据飞轮**，使用越多 AI 越懂用户：

| 数据来源 | 触发时机 | 沉淀去向 |
|---|---|---|
| 日记内容 | 用户手动触发"整理" | → 人物画像 + 心路历程 + 认知洞察 |
| 日记详情对话 | 24h 无新消息自动沉淀 | → 人物画像 + 心路历程 + 认知洞察 |
| 回顾对话 | 24h 无新消息自动沉淀 | → 人物画像 + 心路历程 + 认知洞察 |
| AI 伙伴对话 | 24h 无新消息自动沉淀 | → 人物画像 + 心路历程 + 认知洞察 |

> 自动沉淀产生的变更直接生效，用户事后可手动修改。仅 AI 伙伴心理咨询师角色引导编辑画像时需用户确认。

### 2.1 对话分离设计

三种对话入口各自独立、上下文互不混淆：

| | 日记详情对话 | 回顾对话 | AI 伙伴对话 |
|---|---|---|---|
| **聚焦** | 围绕具体日记 | 围绕一段时间总结 | 围绕"你这个人" |
| **定位** | 记录后的反思 | 阶段性回顾总结 | 人生指导和深度反思 |
| **入口** | 日记详情页内嵌 | 回顾独立入口 | 独立入口 |
| **上下文** | 互不混淆 | 互不混淆 | 互不混淆 |

### 2.2 模块初始化时机

| 模块 | 初始生成时机 |
|---|---|
| 人物画像 | 首篇日记整理后自动生成 |
| 心路历程 | 首篇日记整理后自动生成 |
| 认知洞察 | 首篇日记整理后自动生成 |

---

## 3. 待细化内容

- 24h 无新消息后的沉淀任务调度。
- 自动沉淀结果的证据链、变更历史和回滚机制。
- 用户手动修改与 AI 自动更新之间的优先级规则。
- 跨模块数据更新的一致性与幂等设计。

# 日记管理平台 — 产品设计总纲

> 版本：v2.0 | 日期：2026-07-06

---

## 1. 产品定位

面向个人用户的 AI 驱动型日记与自我认知平台。核心价值是通过日记数据建立深度自我理解，并获得个性化人生指导。

- **目标用户**：个人使用
- **使用场景**：手机端为主要记录入口，手机和电脑端都能查看和管理

---

## 2. 功能模块总览

| 模块 | 定位 | 所属阶段 |
|---|---|---|
| 模块一：日记记录与整理 | 记录原始日记，手动触发 AI 整理，形成可读、可检索、可分析的结构化日记 | 阶段一 |
| 模块二：日记浏览与查找 | 通过日历、时间线、标签和全文搜索查看日记 | 阶段一 |
| 模块三：日记详情（含 AI 对话） | 展示整理后的日记，并围绕单篇日记进行反思对话 | 阶段一 |
| 模块四：定期回顾 | 按日、周、月、季、年生成回顾文档，并支持围绕回顾内容对话 | 阶段二 |
| 模块五：人物画像 | 从日记和对话中沉淀“你是谁”的结构化画像 | 阶段三 |
| 模块六：心路历程 | 呈现观点、情绪、决策和关键转折随时间的变化 | 阶段三 |
| 模块七：认知洞察 | 提炼行为原则、关联发现和底层逻辑 | 阶段三 |
| 模块八：AI 伙伴 | 基于画像、心路和洞察进行个性化深度对话 | 阶段四 |
| 模块九：待办事项 | 管理轻量行动项，承接日记和对话中产生的待办 | 阶段五 |
| 模块十：目标管理 OKR | 以目标、关键步骤和待办组织长期行动 | 阶段五 |

---

## 3. 实施阶段划分

| 阶段 | 包含模块 | 说明 |
|---|---|---|
| 阶段一：日记核心 | 模块一（记录与整理）+ 模块二（浏览与查找）+ 模块三（日记详情） | 日记数据源头，记录→整理→浏览→详情对话的完整链路 |
| 阶段二：定期回顾 | 模块四（定期回顾） | 阶段性总结，生成回顾文档→查看+对话，与日记逻辑一致 |
| 阶段三：自我认知 | 模块五（人物画像）+ 模块六（心路历程）+ 模块七（认知洞察） | 基于日记数据自动生成"懂你"的三层结构化认知 |
| 阶段四：AI 伙伴 | 模块八（AI 伙伴） | 基于画像/心路/洞察的深度个性化对话，五角色切换 |
| 阶段五：行动管理 | 模块九（待办事项）+ 模块十（目标管理 OKR） | 轻量扩展，待办与目标管理 |
| 阶段六：数据飞轮闭环 | 全平台 | 24h 自动沉淀、对话数据反哺画像/心路/洞察的完整闭环 |

> 每个阶段需完成技术架构、数据模型、UI/交互设计、接口与 AI 设计四方面的细化。

---

## 4. 全局导航设计

### 底部 Tab 栏

应用采用底部 Tab 栏导航，四个入口：

| Tab | 图标 | 包含模块 | 说明 |
|---|---|---|---|
| 日记 | 📓 | 模块一 + 模块二 + 模块三 | 日记记录、浏览、详情与反思对话 |
| 回顾 | 🔄 | 模块四 | 定期回顾文档查看与对话 |
| AI伙伴 | 💬 | 模块八 | 五角色深度对话 |
| 我的 | 👤 | 模块五 + 模块六 + 模块七 + 设置 | 人物画像、心路历程、认知洞察、系统设置 |

> Tab 主页面显示底部导航栏；子页面（录入页、详情页等）隐藏导航栏，显示返回按钮。

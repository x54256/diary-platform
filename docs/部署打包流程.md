# 线上镜像打包部署流程

目标：在本地 ARM 机器构建 x86 镜像，上传到服务器，并用原生 Docker 更新线上应用。

## 0. 更新步骤

```shell
docker buildx build --platform linux/amd64 -t diary-platform:latest --load .
docker tag diary-platform:latest 8.138.211.67:5000/diary-platform:latest
docker push 8.138.211.67:5000/diary-platform:latest

ssh root@8.138.211.67
i-7xva84auygwvnq3d5jfr

cd /root/workspace/diary-platform
docker compose -f docker-compose.prod.yml down

docker tag 8.138.211.67:5000/diary-platform:latest 8.138.211.67:5000/diary-platform:backup
scp docker-compose.prod.yml root@8.138.211.67:/root/workspace/diary-platform/
i-7xva84auygwvnq3d5jfr

docker compose -f docker-compose.prod.yml up -d --pull always
```

## 1. 前置文件

项目根目录必须存在：

```text
docker-compose.prod.yml
```

`docker-compose.prod.yml` 内包含应用运行环境变量和数据库配置。

`docker-compose.prod.yml` 包含敏感信息，不能提交到 git。

## 2. 本地构建 x86 镜像

在项目根目录执行：

```bash
docker buildx build --platform linux/amd64 -t diary-platform:latest --load .

docker tag diary-platform:latest 8.138.211.67:5000/diary-platform:latest
docker push 8.138.211.67:5000/diary-platform:latest
```

```sh
# 远程服务器
docker run -d -p 5000:5000 --name registry registry:2
vim /etc/docker/daemon.json
{
  "insecure-registries": ["8.138.211.67:5000"]
}
sudo systemctl daemon-reload
sudo systemctl restart docker

# 本地 docker 也要加上面配置，重启 docker 服务
```

确认镜像存在：

```bash
docker images | grep diary-platform
```

## 3. 导出镜像包

```bash
docker save diary-platform:latest -o diary-platform-latest-amd64.tar
```

## 4. 上传部署文件

服务器部署目录：

```text
/root/workspace/diary-platform
```

创建服务器目录：

```bash
ssh <user>@<host> "mkdir -p /root/workspace/diary-platform"
```

上传镜像包和 compose 文件：

```bash
scp diary-platform-latest-amd64.tar root@8.138.211.67:/root/workspace/diary-platform/

scp docker-compose.prod.yml root@8.138.211.67:/root/workspace/diary-platform/
```

## 5. 服务器更新容器

登录服务器：

```bash
ssh root@8.138.211.67
i-7xva84auygwvnq3d5jfr
```

进入部署目录：

```bash
cd /root/workspace/diary-platform
```

加载新镜像：

```bash
docker load -i diary-platform-latest-amd64.tar
```

停止旧容器：

```bash
docker compose -f docker-compose.prod.yml down
```

启动服务：

```bash
docker compose -f docker-compose.prod.yml up -d
```

## 6. 部署验证

查看容器状态：

```bash
docker compose -f docker-compose.prod.yml ps
```

查看启动日志：

```bash
docker logs -f diary-platform
```

验证访问：

```bash
curl -I http://127.0.0.1/secret/
curl -I http://127.0.0.1/diary/docs
```

浏览器访问：


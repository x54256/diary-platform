# 日记整理目录

实际日记统一保存于本目录，按日记日期分为 `YYYY-MM-DD/`。每个日期目录包含当前整理稿及对应原文、人物资料、澄清记录、转换结果和入库文件。后续修订继续使用原日期目录。

日期未知的文本使用 `未定日期/任务名/`；同日多篇用日期目录下的日记 ID 子目录区分。

## 本次迁移

文件迁移不改动正文或澄清记录。重复副本仅在 SHA-256 完全相同时合并；迁移前后路径及指纹见 `目录迁移记录.json`。迁移前完整备份路径记录在该文件的 `backup` 字段。

迁移前生成的入库包原样保留，其中记录的旧绝对路径没有改写。后续保存必须使用新目录中的当前稿、澄清记录和原文重新执行 prepare，并遵守整篇最终确认流程；旧包不能直接用于继续保存。

合成试跑文件、Skill 评审和代码备份保留在评估目录，不作为真实日记。

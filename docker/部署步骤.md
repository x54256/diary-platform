# 线上镜像打包部署流程

目标：在本地 ARM 机器构建 x86 镜像，上传到服务器，并用原生 Docker 更新线上应用。

基础设施与应用分开管理：

- `docker/docker-compose.infra.yml`：PostgreSQL、MinIO，仅在首次部署或基础设施变更时操作。
- `docker/docker-compose.prod.yml`：应用容器，日常发布只更新该 Compose。

应用快速更新步骤

```shell
docker buildx build --platform linux/amd64 -f docker/Dockerfile -t 8.163.67.208:5000/diary-platform:latest --load .
docker push 8.163.67.208:5000/diary-platform:latest

ssh root@8.163.67.208
i-7xv7k4ffthenduvhw9jd

cd /root/workspace/diary-platform
docker compose -f docker-compose.prod.yml down
docker compose -f docker-compose.prod.yml up -d --pull always

docker tag 8.163.67.208:5000/diary-platform:latest 8.163.67.208:5000/diary-platform:backup
```

如果需要更新 docker-compose 文件：

```shell
scp docker/docker-compose.infra.yml root@8.163.67.208:/root/workspace/diary-platform/
docker compose -f docker-compose.infra.yml down
docker compose -f docker-compose.infra.yml up -d

scp docker/docker-compose.prod.yml root@8.163.67.208:/root/workspace/diary-platform/
i-7xv7k4ffthenduvhw9jd
```

第一次使用需要修改本地和远程服务器的 Docker 配置

```sh
# 远程服务器
docker run -d -p 5000:5000 --name registry registry:2
vim /etc/docker/daemon.json
{
  "insecure-registries": ["8.163.67.208:5000"]
}
sudo systemctl daemon-reload
sudo systemctl restart docker

# 本地 docker 也要加上面配置，重启 docker 服务
```

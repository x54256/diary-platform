# 难例与整理示例

以下示例用于说明整理尺度，其中第 7 节来自实际整理案例。按当前原文判断事件边界和改写尺度，不照搬示例中的事件数量或措辞。

## 1. 同一事件回跳，重复中包含新信息

**原文**

今天排查导出慢，开始以为数据库慢。中午去买面，老板多送了个蛋，还说我最近来得少。回来继续看导出，SQL 其实只用了两秒，主要时间耗在文件写入。我开始还想加索引，后来先把这个想法放下了。导出就是慢，不过这次一万条比上次五千条还慢。

**整理稿**

## 事件：排查导出耗时，发现主要时间耗在文件写入

今天排查导出慢的问题，这次导出一万条数据，比上次五千条还慢。起初以为是数据库慢，想过加索引；午饭后继续排查，发现 SQL 其实只用了两秒，主要时间耗在文件写入，于是先放下了加索引的想法。

## 事件：买面时老板多送了一个蛋

中午去买面，老板多送了一个蛋，还说我最近来得少。

**尺度**：汇聚前后两处排查内容，保留数据规模、最初判断及判断改变；买面的互动独立保留。排查发现不自动上升为方法论反思。

## 2. 观点转变与保留意见

**原文**

开始觉得每天写计划挺烦，反正事情都知道。但昨天漏了给客户回消息，今天列出来之后倒是没忘。所以它也不是完全没用。不过我还是不想把一天安排满，留两三件就够了，先试几天吧。

**整理稿**

## 事件：漏回客户消息后，尝试每天只列两三件事

开始觉得每天写计划挺烦，认为自己反正知道要做什么。但昨天漏了给客户回消息，今天把这件事列出来后就没忘，觉得写计划也有用。不过，我仍然不想把一天安排满，先每天列两三件事，试几天。

### 反思与成长

列计划能帮我避免忘事，但我仍然不想把一天安排满。

## 后续计划

- 先试几天每天只列两三件事。

**尺度**：保留原先判断、具体依据、态度变化和保留意见。反思只整理已经表达的认识；试用计划保留在正文中，同时提取。

## 3. 名称与指代没有充分依据

**人物资料**

主名：林晓；有效称呼：小林；性别：女。

**原文**

小林今天发了个东西，说要接到那个卡诺系统。我没听清系统名，反正她说明天再解释。她说还没测完，我也就没问能不能上线。

**整理稿**

## 事件：小林发来待接入系统的内容，尚未测完

小林今天发了个东西，说要接到“卡诺系统”，但我没听清系统名。她说还没测完，明天再解释，我也就没问能不能上线。

**尺度**：保留有效称呼“小林”，保留用户对系统名的存疑，不将名称猜成某个常见产品；明天解释是他人的安排，不改写为用户承诺完成的任务。

## 4. 身体表现、明确感受与未来意向

**原文**

嗯嗯，刚才录上了吗。今天下午开会的时候手一直抖，后来喝了点水。是不是紧张我也说不准。会后领导让我再讲一遍方案，我有点烦，因为会上明明讲过了。下周可能找他聊聊，还没决定。

**整理稿**

## 事件：开会时手抖，会后被要求再讲一遍方案

今天下午开会时手一直抖，后来喝了点水，但我说不准是不是紧张。会后，领导让我再讲一遍方案。我有点烦，因为会上明明已经讲过了。考虑下周找他聊聊，但还没决定。

### 感受

开会时手一直抖，我说不准是不是紧张。会后被要求再讲一遍会上已经讲过的方案，让我有点烦。

## 后续计划

- 考虑下周找领导聊聊，尚未决定。

**尺度**：删除录音操作自语；身体感受保留，紧张维持未定，烦躁保留原有强度；不添加反思或确定日程。

## 5. 时间关系没有说清

**原文**

今天把申请交了。昨天说材料还差一个附件，后来补了。我记不清补附件是在提交前还是提交后，反正页面现在显示处理中。对了，早上买了牛奶。

**整理稿**

## 事件：提交申请，页面显示处理中

今天把申请交了。昨天提到材料还差一个附件，后来补上了，但我记不清是在提交前还是提交后补的。目前页面显示处理中。

## 琐事

- 早上买了牛奶。

**尺度**：保留未确定的先后关系，不改成“补齐附件后提交成功”；买牛奶作为未展开的琐事保留。

## 6. 澄清关键疑问

### 动作对象影响事件理解

**原文**

让她按着猫，我去找药，猫就跑了。我过敏也难受，后来她帮我找到药，吃了还是烦。

**提问**

原文“我去找药”和后面“找到药，吃了”，这两处找的分别是什么药？

- 两处都是我的过敏药。
- 第一处是给猫用的药，第二处是我的过敏药。
- 不记得，保留原样。

也可以直接填写其他情况。

**回答及使用范围**

用户回答“两处都是我的过敏药”后，可以写“我去找自己的过敏药”。该回答没有说明猫跑掉的原因，不补成“因为我找药耽误了时间，猫才跑掉”。若用户跳过，则保持“找药”，不指定药物归属，也不继续追问。

### 重要名称需要准确拼写

**原文**

下午给那个卡诺系统补了接口测试。

**提问**

原文“卡诺系统”的正确名称怎么写？

- 原名就是“卡诺系统”。
- 我填写正确名称。
- 不记得，保留原样。

若选择填写，请直接提供名称。

**尺度**：缺少上下文依据时不猜成某个常见产品。用户给出的名称仅用于这个对象；已经确认过的同一名称不重复询问。

### 含混内容不影响主要理解

“回家充上电，又坐了一会儿”没有说明充电对象，但未影响所述事件的理解，可以保留，无需为补齐对象打断用户。若具体对象关系到事件关键经过，再提出对应问题。

## 7. 保持日记叙述视角

**原文（两处片段）**

然后这就带哒哒出来溜达了。

遛完回去差不多11点半，回家，回家，回家，回家做饭。做完饭差不多十二点左右呢，就能吃上。

**不合适的改写**

录日记时正带哒哒溜达，想着遛完回去差不多十一点半，回家做饭，十二点左右就能吃上。

**整理稿**

然后就带哒哒出来溜达了。想着遛完回去差不多十一点半，回家做饭，十二点左右就能吃上。

**尺度**：原文直接叙述遛狗和做饭安排，应延续这个视角。“录日记时”是整理者添加的记录场景说明，即使能从上下文推知，也不应加入正文。删除重复、衔接相关内容时，不添加对叙述或记录过程的旁白。

## 8. 重要性分级边界

| 事件内容 | 等级与理由 |
| --- | --- |
| 取回之前办好的材料，准备找时间报销。 | LOW：完成常规取件并留下报销待办，未记录进一步影响。 |
| 想起家人说想吃排骨，买好并腌好，准备中午做。 | LOW：一次日常关心和做饭安排，未记录明显情绪变化或关系进展。 |
| 看到家人晚睡早起，提醒了一句作息不好。 | LOW：记录观察和一般提醒，未记录进一步变化。 |
| 常用买菜站点关闭，感到失落，已经换平台并比较其他购买渠道。 | MEDIUM：原有买菜方式被迫改变，需要实际调整日常采购渠道。 |
| 宠物一度找不到，找了一大圈，担心走失，决定以后减少夜间放开。 | HIGH：寻找经历引起明显担忧，并促成后续遛宠方式的重要调整。 |

**尺度**：买菜、就医、工作、家庭互动都可以出现不同等级，主题不决定等级。有行动或待办不等于有中等影响；要区分常规安排与实际变化。示例等级只适用于表中给出的内容，新增事实应重新判断，不按关键词套用。

### 成对校准

| 常规情形 | 新增影响证据后的情形 |
| --- | --- |
| 想起家人想吃排骨，买好腌好准备中午做：LOW。 | 我们冷战了很久，这次借一起做饭把关键分歧说清，双方决定结束冷战：HIGH，依据是已明确的关系转折，不是“做饭”。 |
| 提醒家人睡得少，未记录后续变化：LOW。 | 这次谈话后，我们确定调整接送安排，让她每天可以多睡一小时：MEDIUM，依据是具体日常安排发生变化。 |
| 听同事介绍面向 AI 的接口设计，觉得有道理，没有记录新的理解：LOW。 | 原先以为包装旧接口就够了，讨论后理解了 AI 使用工具的特点，以及多步调用为何增加出错风险，尚未改代码：MEDIUM，依据是具体认识发生变化，不要求已经实施。 |
| 家人又问了一次什么时候生孩子，我随口应付，没什么感觉：LOW。 | 多次通话都遭到催生和自私指责，阻止仍无效，明显愤怒并激烈争执，反复被要求服从的生育自主边界受到冲击：HIGH，依据是持续压力、强烈情绪和重要边界冲突，不要求关系已经破裂。 |

只按已提供的影响证据调整等级，不为相似主题套同一等级，也不把计划中的改善写成已经取得的效果。

## 9. 反思与后续计划的边界

| 原文 | 处理方式 |
| --- | --- |
| 刚才应该先共情，不该直接命令她。 | 保留在正文，可提取为反思；不生成后续计划。 |
| 这种情况下应该结束对话，先让情绪稳定下来。 | 表达处理方式的认识，不自动提取为后续计划。 |
| 我觉得她应该跟领导说清楚离职时间。 | 保留对他人的建议，不改写成我或她已经决定执行的计划。 |
| 以后她再抱怨工作，我准备先听她说完。 | 提取为后续计划，保留“准备”的承诺程度。 |
| 日记平台的日程功能可以考虑借鉴这种打卡机制。 | 提取为后续计划，保留“可以考虑”的设想程度，不改写成确定实施。 |

**尺度**：是否有明确的未来行动意向决定能否提取，不以是否包含“应该”或是否有具体日期机械判断。反思可以包含行动方法，但方法本身不等于后续计划；用户明确表示今后准备采用，才提取为计划。

### 重要性

LOW：完成常规取件并留下报销安排，未记录进一步影响。

## 11. 标题中的人物角色

| 原文 | 不合适的标题 | 合适的标题及依据 |
| --- | --- | --- |
| 小林之前想去那家餐厅，今天我和她去吃饭，还带了狗豆豆。 | 带豆豆去吃一直想尝试的餐厅 | 和小林去吃她之前想去的餐厅，带上豆豆。明确用餐者和想去餐厅的人，豆豆是随行宠物。 |
| 小林给表妹买了电脑，因为她上大学时舅舅也送过她电脑，这次是回礼。我开始觉得贵，后来觉得能理解。 | 给小林的表妹买电脑回礼 | 小林给表妹买电脑回礼。购买者是小林，省略后容易误读为日记中的“我”。 |
| 小林开车去4S店检查，底盘没问题，店里修复了轮毂。 | 检查底盘没有问题，轮毂做了小修复；小林检查底盘、修复轮毂 | 小林送车检查，底盘没事、轮毂做了小修复。保留送检者，不将她写成检查和维修的执行者。 |
| 妈妈说最近治疗后身体好多了。我起初以为她想停药，继续听才发现她只是在说治疗有效，并没有表达停药意图。 | 身体好转，不准备停药 | 继续听我妈说身体变化，发现她并不是想停药。区分母亲的身体状态与我的理解变化，也不把未表达停药意图扩大为已经决定不停药。 |
| 今天我去取回了之前办好的材料。 | — | 取回材料。没有其他行动者竞争指代，可自然省略“我”。 |

**尺度**：标题压缩后，单独阅读仍须准确理解人物角色。不能以正文写清楚了为由，保留会误导读者的标题；也不要求每个标题都补齐人物或全部经过。

# 开发与评估

结构检查：运行系统 skill-creator 的 `quick_validate.py`。脚本工程验证在项目根目录执行：

```bash
backend/venv/bin/python -m unittest discover -s skills/diary-event-relations/scripts -p 'test_*.py'
```

工程验证必须覆盖：用户隔离和过期来源、完整完整事件范围、同模型合法向量、历史日期与正式／回放边界、事件级前五及稳定排序、完整分批和单对超限、缺失／额外／重复结果、端点与短引归属、幂等保存、冲突修订保留旧版、依赖修订失效及未完成不能交付。入库还需覆盖最终稿修订改变指纹、独立包脱离本地目录仍可用、三种判断完整归档、零关系发布、重复发布幂等、拒绝覆盖其他发布、错误用户／活动任务／过期来源拒绝，以及证据写入失败整体回滚。SQLite 用于来源适配与发布事务隔离测试，不声称验证 PostgreSQL 的全部行为。真实 PostgreSQL 测试仅允许显式 `RELATIONS_TEST_DATABASE_URL` 指向一次性本机 `127.0.0.1:55449/graph_test`，验证 ORM 全量真实约束、固定迁移、幂等发布、证据失败回滚及用户行锁；容器不挂载正式数据，结束后删除。正式数据库只读准备与预检，不写库。

语义由 agent 判断，不能靠结构测试或示例通过率代替。使用干净上下文的独立 subagent 进行前向试跑，只给 Skill、任务和最少来源资料，不给预期答案、曾经错误或主审标签。输出到隔离临时目录，不动正式数据。完成后再按源事实审阅真实行为，并区分内容错误、协议问题和执行环境限制。

09-09、09-10 既有实验是开发参照而非用户逐条确认真值：包括新学习安排与已执行的区别、争吵后复盘、泛指 AI 焦虑不能自动定位具体职业事件、同日状态未决及牙科主题负例。不能为了复现旧答案调整新结果。回归时同时检查是否漏关系、误连、类型／方向／确定性错误、证据不足、描述主体漂移。

另外必须覆盖不在旧样本中的明确提及、推测触发、计划重复负例、发生日期与记录日期不同等场景；构造用例与真实日记分开报告。引发和提及的构造通过不等于真实正例验收，正式整体验收仍需补充真实正例及未参与设计的保留集。

召回与判断分开测：完整配对参照用来发现未召回关系，固定候选用来比较判断。保留相似度阈值与前五的独立遗漏来源；不只测被召回的正例。输出一致率、工具校验通过率都不能直接称为准确率。宿主 Token 不可得时记未知，不按字符估算收费。

稿件转换需验证：RELATED／NO_RELATION／UNRESOLVED 完整往返、人工修改覆盖陈旧 JSON 缓存、重复 render 不覆盖人工稿、离线 convert、包内稿件与结果绑定、折叠区完整性、删除／重复事件对／端点错配拒绝、多行原文及 Markdown 字符保真、旧版包可查询而不可写入。独立前向验证应通过真实 CLI 改稿并保存至隔离数据库，不只调用解析函数。

事实澄清行为验证需覆盖：具体指代歧义问一次且问题自包含、重复事实跨对去重、同主题负例不追问凑关系、来源推测不升级、跳过／不记得／禁止提问后保留未决并停止追问、回答新增事实需先修订正式要点、局部回答不冒充整稿确认。用构造来源验证行为，与真实日记的关系准确率验收区分。

提问详情验收：单独查看实际交互工具中的一道题，不提供前文或文件。该题应包含所有相关事件的日期、标题、要点编号和足够判断的详情原文，读者能据此理解指代及歧义；只有摘要、孤立短语、“见上文”或稿件链接视为失败。长要点用例需检查摘录是否保留影响判断的上下文；用户指出缺少内容后，应补齐材料重新提问。澄清记录应保留实际展示材料，不能用事后补写的详情冒充当时已展示。

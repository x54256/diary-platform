## 5. 步骤四：真实双路检索

对当前每个事件的每条 detail 分别查询。两路限定同一用户、此前日记日期、历史已入图；语义额外限定同一向量模型。关键词由数据库 layer1_zh 分词并去重，OR 匹配、ts_rank 降序；无最低 ts_rank 门槛。语义在 SQL 中过滤余弦距离≤0.5，再按距离升序。两路各最多 10 条，同分用要点 ID 稳定排序，不补足。

### 关键词 SQL

```sql
WITH query AS (SELECT CASE WHEN count(*)=0 THEN NULL ELSE
        to_tsquery('simple',string_agg(quote_literal(word),' | ' ORDER BY word)) END AS q
        FROM unnest(tsvector_to_array(to_tsvector('layer1_zh',:detail))) AS word)
      SELECT p.id::text,p.event_id::text,p.no,
        ts_rank(to_tsvector('layer1_zh',p.detail),q.q) AS score
      FROM graph_event_points p JOIN diary_events e ON e.id=p.event_id CROSS JOIN query q
      WHERE e.user_id=:u AND e.diary_date<CAST(:date AS date) AND e.is_in_graph
        AND to_tsvector('layer1_zh',p.detail)@@q.q
      ORDER BY score DESC,p.id LIMIT 10
```

### 语义 SQL

```sql
SELECT p.id::text,p.event_id::text,p.no,p.embedding<=>CAST(:vec AS vector) AS distance
      FROM graph_event_points p JOIN diary_events e ON e.id=p.event_id
      WHERE e.user_id=:u AND e.diary_date<CAST(:date AS date) AND e.is_in_graph
        AND p.embedding_model=:model AND p.embedding IS NOT NULL
      AND (p.embedding<=>CAST(:vec AS vector)) <= (1 - :min_similarity)
      ORDER BY distance,p.id LIMIT 10
```

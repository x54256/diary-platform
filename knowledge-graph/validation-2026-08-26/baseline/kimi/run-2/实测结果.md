# 跨模型通用示例方案：实际输出

同一原文与r5通用示例提示，未输入当前事件答案或助手反馈。

## 1. 怀念过去的很大原因是现在过得并没有那么好；其实现在还行、工作压力没那么大，但乐趣没那么大了。

今天可能是因为于海昕要来，我又开始怀念过去，怀念以前在淑慧的日子、杨龙还在的日子。下午我在想为什么会怀念过去，很大原因是因为现在过得并没有那么好。其实现在过得还行，相较于外面的生活环境，我的工作压力没那么大，但是没有那么大的乐趣了。

## 2. 以前有同事说笑、上班有点意思，现在没有搭子、干什么都是自己一个人，上班的快乐可能也不在了。

以前可以和同事，比如德华、老陆、于福豪、万世威、殷萧鹏，一起说说笑，上班至少还有那么点意思。现在没有了搭子，干什么都是自己一个人，还有一个同事自己不太喜欢，反正上班的这种快乐可能也不在了。

## 3. 现在工作基本上让AI去做，解决问题的创造性快乐没有以前那么强了；但日记管理平台跑通时还是挺开心的。

现在有了AI，创造性的快乐也少了。以前解决了一个问题、设计了一个什么系统、做了一个工具，就会觉得很开心；现在基本上都是让AI去做，就没有那么开心了。当然，我做日记管理平台跑通了，还是挺开心的。

## 4. 工作本身没乐趣：项目普通，精力主要花在梳理产品经理和项目经理没理清的需求。

再一个就是觉得干的这些工作没有什么乐趣了。一个是因为AI，一个是做的这些事本身都是很普通的项目，做一做增删改查，其实主要的精力花费在把产品经理和项目经理没有梳理清楚的需求给梳理清楚这件事情上。
